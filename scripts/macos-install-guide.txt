@APP_DISPLAY_NAME@：首次启动说明

先将 @APP_NAME@.app 拖入“应用程序”。以下仅用于可信安装包；损坏或恶意软件提示请勿绕过。

1. 开启“任何来源”
sudo spctl --global-disable
输入管理员密码后，仍需回到系统设置 → 隐私与安全性 → 安全性，选择“任何来源”并确认。

2. 在系统设置中允许打开（推荐，不必开启“任何来源”）
先启动一次，再进入：系统设置 → 隐私与安全性 → 安全性，选择“仍要打开”并确认。

3. 若仍被下载隔离标记阻止，在“终端”执行
xattr -dr com.apple.quarantine "/Applications/@APP_NAME@.app"
open "/Applications/@APP_NAME@.app"
