# 模型特征与打印效果优化：商用落地方案

## 1. 最终交付什么

对同一个待打印模型，给出**测得什么特征、可用哪项 Orca 能力、候选切片有哪些变化、增加多少时间和耗材**。2026-10-18 用户确认当前先完成分析和对比，不设时间/耗材上限，不新增自动择优；现有模板匹配、支撑/附着及 Arachne 建议保留。下文自动选择部分是后续条件，不是本轮已开启的流程。

模型修复完成后才进入本流程。这里不再次重建模型，不修改源文件，不替用户发起打印。复用现有调用：Blender 分析几何特征，PAM 匹配模板及少量改参，PDS 执行 Orca 切片，Orca 提供实际切片指标。客户端入口和通知不变，不新建业务平台。

“商用”是验收目标，不是当前状态：软件指标需要验证，打印质量需要机型/喷嘴/耗材/工艺实印标定，依赖授权需要单独完成。本方案不以一个通用分数代替这些检查。

## 2. 分析哪些特征，用哪些原生能力

| 特征 | 必须得到的具体指标 | 复用 Orca 原生能力 / 主要参数 | 采用优化前要确认 |
|---|---|---|---|
| 薄壁、细字、细小凸起 | XY 局部宽度 mm、目标材料区路径覆盖率 %、丢失笔画数 | Arachne、`min_feature_size`、`min_bead_width`、各类线宽 | 细节增多且不堵孔、不粘字；不能只看总挤出量 |
| 细杆、连接颈 | 最小局部宽度 mm、断开数、分支保留率 % | 墙圈、填充密度/图案、已标定线宽 | 连接保留；墙圈增加不代表 STL 细杆变粗或强度已合格 |
| 浅浮雕、薄片 | Z 高度 mm、有效细节层数、分层高度误差 mm | 层高、原生自适应层高 | 目标高度得到表达；增加顶层数不能恢复未采到的细节 |
| 曲面、斜面 | 分层几何偏差 mm、重要表面误差分布 | 自适应层高、轮廓分辨率、外墙速度 | 偏差降低且时间增量可接受；不是实物粗糙度预测 |
| 悬垂、悬臂 | 下向面坡度 °、逐层无承托面积 mm²、伸出距离 mm | 悬垂降速、普通/树状/有机支撑、支撑阈值 | 实际承托到位；单开支撑不算通过 |
| 桥接 | 双端锚定比例 %、无承托跨度 mm | 自动桥接方向、桥接速度/流量/风扇 | 仍有锚定，且落在该机料的实测能力内 |
| 浮空起始区域 | 无下层/支撑且不能桥接的起始区域数、面积 mm² | 自动支撑与支撑接触设置 | 不能因为上层最终连在一起就忽略起始浮空 |
| 小脚、窄底、大平底 | 每个接地区域面积 mm²、最小有效宽度 mm、辅助附着范围 | 自动 Brim、Brim 宽度/间隙、首层线宽/速度；必要时 Raft | 模型接地与辅助接地分开算，孔缝不被侵入 |
| 高瘦结构 | 高宽比、局部底部宽度 mm、外墙速度/加速度 | 小轮廓降速、外墙速度/加速度、Brim | 只提示稳定性风险，不能输出倾倒概率 |
| 孔、槽、活动间隙 | 目标间隙 mm、计划边界偏移 mm、新闭合/粘连数 | 孔/轮廓补偿、象脚补偿；特定孔才考虑 polyhole | 保持用户公差，未给配合要求不自动改变关键孔缝 |
| 顶面与底面 | 实际实体厚度 mm、有效实体层数、下方跨度 mm | 顶底壳层/厚度、单调填充、适用平顶面的熨烫 | 封顶质量与时间权衡；不能拿熨烫修复侧面层纹 |
| 小层、尖顶 | 预计层时间 s、短时间层比例 %；后续局部重访时间 s | 按层时间降速、最小速度、风扇控制 | 使用对应材料标定；整层时间不是局部温度 |
| 短线段、小轮廓、尖角 | 线段长度 mm、路径数量、计划速度/加速度 | 小轮廓降速、外墙速度/加速度、轮廓分辨率 | 不能为减少线段而消除原有细节 |
| 空移、回抽、接缝 | 空移长度 mm、回抽次数、接缝分布；实印拉丝情况 | 原生接缝策略、擦拭、已标定回抽 | 次数减少不等于拉丝变少；不从几何猜最佳回抽 |
| 流量需求 | 计划流量 mm³/s、对应耗材上限、超限路径比例 % | 原生最大体积流量限制、相关角色速度 | 用最终计划值，不把限流前需求误报成最终超限 |
| 内部结构与成本 | 各角色时间 s、耗材 g/体积 mm³、总增量 % | 自适应立方、支撑立方、闪电填充、墙/填充参数 | 不以省料牺牲连接、顶面或已指定强度要求 |

所有尺寸基于**最终摆放、缩放、对象/区域覆盖和有效参数**。不把三维厚度、XY 宽度、Z 高度混成一个指标。孔缝是应保留的空白，不能算作“欠填”。模型尺寸、预设名称不能替代实际切片证据。

仍缺的软件能力包括：通用笔画/分支对应、任意曲颈局部截面、融合浮雕的基底与细节分割、最终外表面阶梯误差、结合打印时序的承托/浮空判断、任意曲槽及三维贯通关系、局部有效接地宽度、有效实体层数与封顶跨度、局部沉积重访时间。重要表面、必须保留的连接/笔画、浮雕基底、配合面与公差、重访邻域等需明确目标输入；不能用包围框或整体分数代替。Blender 独立质量入口已有局部细杆候选算法，但模板入口没有直接套用其工艺阈值，不重复开发，也不把它当完整细颈识别。

上述算法缺口与实印标定分开记录。当前不新增速度/冷却选择、时间/耗材上限或自动择优；已有模板、支撑/附着和 Arachne 建议照原规则保留。缺少这些后续自动决策条件，不妨碍查看已经测得的分析与对比数据。

### 2.2 本轮先接通的正常调用链

1. **现有高级参数请求**仍触发模板分析。PDS 从已有模板解析外墙线宽；Blender 在原任务、原模型导入中增加墙分析，不额外再发一个分析任务。
2. **PAM**保留原支撑/附着规则；明确检测到窄特征时，针对 Orca 增加 `processOverrides.wall_generator=arachne` 建议，不批量覆盖墙参数。
3. **现有切片请求**复用已完成的模板匹配记录，把适用建议合入原 `otherParams`。是否替换模板与是否采用墙建议分开判断：没有映射 ID 时保留原模板，也可在原模板明确且线宽一致时采用建议；原模板未知则不猜测。客户端不用新增请求或转发字段；未匹配、旧记录或未知结果仍按原流程执行。
4. **Compare**仅修改匹配候选，不修改基线。原模板 JSON 记录墙生成器是否被实际手动修改；源模板默认值不自动视为手调，真实手调和来源未知的历史副本保留，实验快照冻结该记录。不新增业务版本、表或客户端参数。
5. **切后报告**沿用 PDS 的 `source=compare`：同次 Orca 输出完整 `plate_1.analysis.json`，PDS 流式校验后原样上传至现有文件存储，任务表的可空 `slice_analysis_url` 列只保存地址，原查询返回 `sliceAnalysisUrl`。Compare 保存并透传地址，Web 点击加载时读取文件，同地址共享缓存；不把完整报告内嵌进任务 JSON。普通 APP/Cura 不请求报告，不增加空返回字段或通知。部署前检查数据库现状，执行本轮加列 SQL，再配套部署 Orca、PDS/interface 与 Web；旧开发稿的 `slice_analysis` 不是当前字段，不盲目重复执行迁移。

线宽不使用固定的 0.42 mm。缺失的继承配置不能猜值；分析与采用模板的外墙线宽必须一致。主服务的分析缓存当前是原朝向，因此隐式模板和墙建议都核对同模型、同缩放、未翻面的单模型条件；Z 旋转/XY 平移可保留，XY 翻转、换文件、拆件和多模型不复用原分析。手动模板和客户端六项参数仍优先，不重跑分析或新增调用。

墙扫描可以在找到明确阳性后提前停止：这足以生成该条建议，但不代表完整扫描通过；未知/失败不生成建议。自动建议只切换墙生成器，用户显式设置仍优先。此接入不宣称 Arachne 在所有模型上都改善，更不等于后续 16 类指标、全自动候选验收或实印标定已经完成。

当前 Compare 的既有 B 组仍可能在切片内执行高级修复，其特征分析早于这次修复。该模式的 A/B 不能直接解释为“同一几何只改参数”；参数效果验收应使用已经确定的同一最终模型。本轮没有扩改原修复编排。

## 3. 当前对比规则与后续采用条件

当前只记录基线和候选的数值变化，不自动评出胜者。Compare 复用原实验页及历史结果：同输入/变换、机器、材料且修复方式已记录才计算差值；只要参与修复就提示“非纯参数对照”。局部覆盖还要求分组和各截面 Z/层高一致，不同层高不按序号硬比。实心填充区域可能随工艺变化，即使数值可相减，也不据此判定改善。缺报告、重试未成功和未知值都不沿用旧值。

原10项对比和原实验CSV保持；另有“更多指标对比”及独立CSV，覆盖整板贴床面积、空移总长、逐材料峰值/超cap距离/冷却层时间、各角色运动范围与耗时用料。材料按唯一索引、路径按唯一角色配对；比例之差用百分点，不再计算一个相对百分比。两侧cap或冷却条件不同，只停算依赖该阈值的差值，原始测量仍可查看。局部层、底面和贴床区域不按数组序号硬配，不把正负差值自动判为改善/恶化。

以下为以后开放自动采用必须满足的条件，本轮不实现第 4 项的自动选择：

1. **基线**：保留原模型与原有效参数的成功切片结果，先测量再改参。
2. **有依据才尝试**：指标指出具体风险后，仅修改对应的一组原生参数；首次实现一条规则最多一个候选，不批量搜索所有参数。
3. **同条件比较**：同一模型、摆放、机料及目标区域，只改变已声明的参数。不同层高按物理 Z 对齐，不按层序号硬比。
4. **满足约束才采用**：目标指标改善；未引入已检查出的断连、堵孔和无承托起始打印；时间/用料增量在业务明确给出的上限内。关键结构未检查完，不能自动采用有结构风险的修改。
5. **不确定就保留基线**：规则不适用、候选失败、检查不完整、没有标定或超成本上限，均保留已成功的原切片方案并记录原因。没有成功基线则报告原切片失败，不伪造可打印结果。

阈值分三类：机器硬约束来自设备配置；材料/桥接/冷却等能力来自实测标定；关键间隙和成本上限来自业务要求。**不预填一套“所有 PLA 通用”的合格阈值。**

## 5. 首批实现边界

在既有 `--slice` 命令加 `--slice-analysis-report`，并明确 `--outputdir`。每个完成切片的盘输出 `plate_N.analysis.json`，既有 `result.json` 保持不变。报告只读取同次切片数据，不再次切片，不进入修复流程。

统计是观察数据，不输出“最佳参数”“可以打印”“强度合格”。首模型层截面面积**不是直接接地面积**；另有按底部 Z 判定的模型计划底面占用面积，离床/垫层为 0，不含辅助附着也不等于实际粘附。G-code 层时间是估算的层变更序列时间，**不是每个部件的局部冷却时间**。名义流量是指令速度乘以每毫米材料体积，不是实测出料量。

逐层计划覆盖来自生成 G-code 前的墙和填充，不含支撑/Brim/Raft，也不包含导出时接缝裁切、斜接、螺旋等变化。整岛无路径不覆盖部分分支丢失；孔区侵入不等于间隙或孔闭合；完整截面未覆盖含正常稀疏填充，实体表面未覆盖也可能来自用户降低顶底面密度。全部数值只提供对比证据，不把空白面积自动标成缺陷。

相邻层指标比较的是**模型截面的平面投影**，不是最终挤出材料或支撑的接触判断。保留前后层采样/打印高度及间隙；首模型层比较项为 null，错误或不合法层序不生成完整结论。开启支撑不会抹掉原模型超出下层轮廓的事实。桥接计划按三种角色分别统计，路径片段不等于独立桥数量，总长不等于桥跨度，逐层面积和不等于投影并集或体积。Web 本批仅逐组单实例展示，不新增这些指标的 A/B 差值。

外部桥接新观察只分析开放的 `bridge_infill` 路径：对照前一模型层计划材料足迹，将未覆盖中心线沿原路径合并为连续段，并分别记录所有段和“两侧在同片段内都有覆盖”的子集数量/最长弧长。点接触和沿边界重叠不算内部覆盖；不跨独立路径拼接。首层或不支持/不完整数据保留未知。正常稀疏间隙也可产生这些段，不能由数量或长度直接认定缺陷；尚未结合支撑、实际接触、同层先后或机料能力，不引入合格阈值。

“前后有覆盖”只描述沿路径的顺序：单侧悬臂从同一支承区域伸出再折返，也可能符合。真实CLI已核对该反例，页面按此明确命名，不能将它当作空间上两端都有承托、桥接强度合格或自动免支撑条件。各批原生、真实CLI及消费/页面证据见实施记录；未改普通切片或自动采用规则。

支撑投影是独立观察：目标为本层超出前一模型截面的部分与本层墙/填充足迹的交集；首层使用全部模型计划占用。整板当前支撑路径按实例位置统一，包含筏层，不用合并前备份或支撑开关代替实际路径。每部分目标只匹配不高于模型本层打印高度的最高支撑路径，记录相交面积、支撑打印 Z 与模型名义底面差值；零/负差值保留。首层无前层不阻止筏层观察；没有路径是已知空，非法数据是未知。Web 按组/实例/模型层展示同一条匹配，不拼接不同层的最小差值和最大面积。

每个支撑高度行另列“中间高度模型路径投影面积”：只取支撑打印Z与目标模型打印Z严格之间的模型计划路径，与这一行已分配的目标区域求重叠；全板所有实例参与，重复投影只计一次。没有匹配行不算0；同Z不适用、资料不完整为未知，不影响旧匹配。此项不使用实心截面代替稀疏路径，也不计算路径厚度跨入，因此仍不是实际三维遮挡或有效支撑。按对象打印时，不能据此假定其他对象材料已经打印；正面积、0面积都不是质量结论，不自动改变参数或候选选择。

源部件 Z 采样针对文件中已有的正向部件，不自动分出融合 STL 内的文字/浮雕；有路径仅指该位置与路径足迹存在正面积重叠，不证明完整保留。二维连接与闭孔计数也不代表三维强度或开口槽缝状态，正常稀疏填充可能产生多块覆盖。报告页按组展示各指标的单层最大值，不把跨层累加当真实部件/孔数量；不完整数据保留未知。

新三维名义连通按同一对象的单实例统计：T 是补偿后各区域截面按模型层厚形成的目标，M 是模型墙/填充路径按自身宽度和高度形成的名义材料，C=T∩M，D=T\M。分别跟踪 T、M、C 的连通组件，记录每个 T 的体积、D 的体积与分层位置范围、内部 C 的数量，以及同一 M 连接多个 T 的情况。不含支撑、其他对象/实例或打印时序；目标已经过切片和补偿，不能检出在形成 T 之前就消失的源模型细节。C 多块仍可能通过目标外的 M 相连；D 包含正常稀疏填充空白，不直接称为断裂或缺陷。范围框只用于定位，不代表未覆盖区域的实际形状或最小宽度。编号仅在本报告内有效，不跨 A/B 按编号配对；未知保留 null，合法空目标为 []。

本三维块的目标T、路径M、覆盖C及未覆盖D采用同一套精确集合计算，保留微小区域和孔洞，最后输出时才换算数值。原截面的每个外环与显式孔分别解释，原宽度轮廓按每条路径独立解释后合并；交叉闭合轮廓按NonZero规则确定内部，不把代数面积当实际覆盖面积。点触与共边连接分开，跨层只在正面积接触时连接。层/高度不完整或JSON无法表达正区域时新块未知；内核一致性异常则报告失败并保留G-code，不人为补0、扩大边界或截断体积。精确针对既有XY轮廓与量化Z构成的名义集合，不消除前序切片、offset及浮点输入误差，也不能恢复形成T之前丢失的细节；不代表原网格、最终沉积形状或实印误差全部精确。不改实际切片和原有报告，性能优化后续安排，当前验证见实施记录。

开放空白观察不靠人为围框或补缝距离：只计算真实计划路径围成的空白中，原本连通源截面外界的部分；排除源实体、原闭孔及嵌套材料。它能补充开口变成围合空白的证据，但完全填满后也可能为零，不能单独判定槽缝保留。新两项单独兼容旧报告，不影响此前六项区域计数，不增加自动选参。

分离区域间距针对同组同层 `lslices` 中不同正面积岛的轮廓和孔边界，双向顶点到线段计算最短距离，单位 mm，不以包围盒距离代替实际边界。完整且不足两个岛为不适用，检查不完整为未知；0 可表示点接触，不能直接判定粘连。Web 取可测层的最小值，不与原计数的最大值混淆。象脚补偿层的 `lslices` 保留补偿前截面，所以这项不是补偿后路径间隙；同岛 U/C 槽、连接颈、不同组/实例之间的距离和三维活动余量均不在此项范围。原有中轴线算法服务于生成路径，带宽度/角度过滤和短支删除，暂不把它改名当无阈值的颈宽测量。

外墙、填充、支撑与启动预挤出按路径角色分开统计，避免把启动动作估算的宽度或高度当作模型尺寸。首批也不输出“细字保留率”“孔缝合格”等尚未实现的局部分析结论。

默认关闭是避免给普通切片增加报告成本，不是维护两套业务版本。现有报告开关同时控制G-code解析器的额外统计：关闭时保留原耗材/估时/预览，不记录分析运动、流量及层用料元数据；开启才收集并导出报告，不增加新参数。共享核心不写回打印参数或路径，GUI 无新增控件或自动改参。报告输出使用独立任务目录，拒绝覆盖旧报告；显式要求报告但生成失败时返回失败并保留已有 G-code，不能把旧报告当成本次结果。

业务承载采用现有文件通路：PDS 对完整 `plate_1.analysis.json` 流式校验后原样上传，只在任务中保存 `sliceAnalysisUrl`；Compare 直接透传地址，Web 按需读取后展示/对比，不把几十万条区域明细反复内嵌到接口和数据库 JSON。文件内容不删减、未知值不改为零；普通 APP、Cura 和固定测试 G-code 不增加报告字段。报告计算仍计入现有进程超时，文件承载修复不能替代计算耗时验收。

超时按用途分开：普通Orca任务继续使用 `print3d.common.slice-process-timeout-seconds`，默认180秒；Compare报告任务使用 `print3d.common.slice-analysis-process-timeout-seconds`，默认1800秒，可按测试服务器配置调整。两者都约束整个Orca进程，包含切片和报告计算，不含排队、下载及后续上传。超时终止进程树、返回124并记录失败，不把已生成的本地G-code或半份报告交付为成功。Compare异步查询，不需要把单次HTTP读超时改成30分钟；默认一小时未终态转待确认并继续核对远端任务，明确失败不自动重算。延长分析任务预算仅用于完成低配Linux功能联调，不证明吞吐或并发已通过。

### 7.2 既有业务链联调

只在用户的测试环境执行，不连接生产数据库或发起打印。部署顺序：原 PDS V20261018__add_slice_analysis_to_slice_job.sql 可空列迁移 → 含当前代码的 Orca → 相应后端/Web；Blender 包需同时包含复用的纯测量模块。

Linux必须使用包含本次提交的原生构建，而不是旧发布分支的安装包。先单任务完成小模型，再运行复杂模型并记录实际CPU／内存限额、完整耗时、峰值RSS、报告大小及上传／读取结果；不能用Mac约388秒／3.2GB记录推算Linux上限。普通任务预算保持原值，报告任务测试默认30分钟；若被系统因内存不足终止，增加时间无效。该轮仍需普通GUI／CLI同参回归，不触发实际打印。

1. 用同一最终模型走原特征分析 → 模板匹配 → 原切片 → Compare 查询/刷新。APP 入口、客户端六项参数与通知不新增要求；Compare 才请求切片报告。部署前先执行 PDS 本轮未部署的 `slice_analysis_url` 加列 SQL，再配套部署服务/Web；页面按需加载报告，轮询不得重复下载，同地址复用，读取失败明确提示且不显示为零。验证对象存储对网页来源的跨域 GET，返回 JSON 与本次原文件一致。未执行过的线上迁移/存储/HTTP场景仍待联调。
2. 同线宽的候选允许现有 Arachne 建议；手动墙值优先。喷嘴覆盖、多色/多喷嘴、未知继承或分析/采用线宽不一致时跳过自动墙建议，不能阻止正常模板和切片。
3. 换文件、翻面、缩放、多模型不能误用原特征缓存；A/B 使用同一最终模型。B 组含修复时显示“非纯参数对照”，不伪称只改参数的改善。
4. 历史缺字段、重试失败、损坏/缺失报告分别处理；失败不得显示旧 G-code、旧特征或完整结论。新原始 JSON 可查，A/B 与 CSV 原 10 项和人工记录仍正常，不自动评胜者。
5. Compare 展开新明细，核对 mm/mm²/mm³/s、负坐标与微小正值、单实例和整板口径；完整零/未知/不适用分别显示，接缝、模型层和贴床区域分页20条且不丢数据。不同层高不按层号强行算局部差值。
6. 展开“更多指标对比”，核对材料/角色乱序后对应仍正确，缺失/重复身份不补零，cap或冷却阈值不同仅停算相关差值；分角色时间为秒、长度为米、质量为克，比例差为百分点。下载独立CSV核对页面原值与条件说明，原实验CSV保持不变。
7. 使用实施记录中与当前程序对应的报告，展开三维名义连通明细：核对目标体积、未覆盖体积、目标内路径组件和跨目标关联与原 JSON 一致；位置为对象局部 XY/打印 Z，非整板世界坐标。分别核对全覆盖、全无路径、内部多块、跨目标连接、合法空目标、未知及失败任务，合成反例不能冒称真实样例已出现。目标、跨目标关联和未覆盖分层位置各自分页20条且不丢数据；同一编号不跨候选配对，稀疏空白和多块不自动标失败。当前新块准确性/复杂模型成本未收尾时，保留该项待验，不引用旧构建判通过。
