02

顶层 3 个字段

字段 / 类型含义与使用方式
return_codeinteger本次任务的结果码。0 = 任务正常返回，不等于模型没有问题。非 0 表示参数、导入、导出、检测或高级修复等阶段失败，或高级修复没有可保留进展。例：-25 可用于高级修复失败／无进展，-27 是检测失败码；不要只靠某一个码推断全部原因。
error_stringstring任务错误说明。正常返回时为 ""；失败时用于显示或排查。它是文字，不是稳定枚举，不要匹配英文句子决定业务分支。部分修复也可能为空，因为任务已正常保留成果。
model_checksobject[]模型检测摘要数组，当前一次处理一个模型，固定一个元素。业务读取 model_checks[0]。其中问题数量对应当前保留模型；检测未取得时 issues = null。
03

模型摘要 6 个字段

以下字段全部位于 model_checks[0]。除 issues 可以为 null 外，均按表中类型返回。

字段 / 类型含义与使用方式
schema_versioninteger返回数据的格式版本，当前为 4。不是 Orca 或 CGAL 版本。用于选择解析规则；之前已经生成的 v3 JSON 不会被自动改成 v4。
mesh_statusstring · 3 个取值当前模型的检测结论。passed 当前检查范围通过；needs_repair 至少一项基础几何问题已确认；unknown 未确认基础异常，但也无法完整判定。它描述模型，不描述进程是否成功。
check_completeboolean整套检查是否完整。包括七项和内部部件／包含关系判断。true 不等于没有异常；false 不等于还在运行。即使七项各自均为 complete: true，内部判断未完成时这里仍为 false；精简字段不取消内部安全检查。
input_materials_ignoredboolean成功导入时，是否按纯几何忽略源材质。缺少 MTL 自动降级或显式忽略材质时可为 true，界面可提示“源材质已忽略”。false 不是“保色验收通过”，也不保证 UV／贴图往返；导入失败时不能据此判断保色结果。
repair_statusstring · 7 个取值本次 CGAL 高级修复的状态。区分未请求、未开始、无需修复、完整修复、部分修复、无进展和失败。它不记录 STL 导入时是否已执行 ADMesh 自动修复。完整取值见下面的状态表。
issuesobject | null当前七项几何问题，每项都有 count 与 complete。取得结果时七项都返回，即使数量为 0；根本没有取得检测时为 null，不能把 null 当成“七项均为 0”。不再返回修复前对照、部件详情或面／边坐标。
04

七项问题：数量到底在数什么

count · 非负整数

已确认的数量。不同项的单位不同，是边、顶点、面、组或相交对；不要相加当成“独立缺陷总数”。

complete · 布尔值

当前这一项是否查完整。false 时 count 只是下界，应显示“至少 N”；0 + false 不是没有问题。
issues 下的键中文含义 / 计数口径
boundary开放边：仅被一个非退化面使用的几何边数。一个洞可能有多条边，4 条开放边不等于 4 个洞。
nonmanifold_edge非流形边：被三个及以上非退化面使用的边数。
nonmanifold_vertex非流形顶点：顶点周围的面连接不构成单一路径或单一环的顶点数，例如仅共点连接的异常结构。
self_intersection自相交对：相交的三角形对数。56 对不等于 56 个独立区域，也不能直接换算成 56 个洞。
degenerate退化面：当前检测口径为精确零面积的三角面数，不是所有“很小／很细”的面。
duplicate重复面组：不区分绕序的重合面分组数。三个相同三角面属于一组，不是三组或三对。
orientation局部朝向冲突：恰有两个非退化面沿公共边方向相同的边数。不是已经移除的“整体壳体朝向”检测。

路径示例：model_checks[0].issues.self_intersection.count。这些数字描述当前模型，不是本次修好了多少。

05

高级修复状态：完整取值

repair_status可以怎样理解 / 展示
not_requested未请求 CGAL 高级修复。不代表没有自动修复：本检测入口对 STL 的原生导入仍会执行 ADMesh。
not_started请求了 CGAL，但参数、导入或检测等提前失败，还没进入高级修复。
not_needed请求了 CGAL，但原生导入后的检查已通过，无需再执行高级修复。
repaired高级修复成果已导出，并且复检通过。可显示“已修复，当前检查通过”，不承诺切片／打印通过。
partially_repaired已保存有效修改，但仍有异常或未完成判断。可显示“部分修复，仍需处理／确认”，不能显示“全部修复成功”。
unresolved高级修复没有可保留进展，任务返回非零。保留原生导入后的基础副本；不是“做了有效修改但未修完”。
failed高级处理、导出或重读复检失败，任务返回非零。有已发布基础副本时仍可保留，但失败候选不作为当前成果发布。
06

业务接入：按这三个层次判断

  1. 任务：看 return_code 和 error_string。正常返回只是拿到了结果。
  2. 模型：看 mesh_status、check_complete 和 issues。已确认的问题可以展示；未查完整不能按零问题处理。
  3. 修复：看 repair_status。部分修复有成果，失败也可能有基础副本，两者必须区分。模型仍正常导出，但这个 JSON 不再提供文件路径或下载清单。

只有同时满足以下条件，才显示“当前检查通过”：

return_code === 0
&& model_checks[0].mesh_status === "passed"
&& model_checks[0].check_complete === true

通过只覆盖当前网格检查，不等于已经完成切片、逐层预览或实物打印验证。
