# 红框孤立基底条：承托关系遗漏与 Xmaker 差异

2026-09-21。复核用户红框截图和 09:41 GUI 导出的真实 G-code；仅分析，没有修改切片算法或参数、没有编译或实机打印。

后续状态：用户确认优化后，已补齐下述保守清理源码和回归用例，等待用户重新编译。初次分析结论保留；最新实现与验证范围见 [试印进度](raft_geometry_trial_progress.md) 文末「孤立基底清理」。不以 Xmaker 外观作为验收目标。

## 1. 结论及证据

红框对应首层筏层中的一条孤立长带，从当前路径的承托用途看属于多余残留。它不是小于 1 mm 的短路径，也不是面积小于 1 mm² 的碎点；上一轮这些指标和专项通过，没有覆盖这类问题。

| 项目 | 09:41 G-code 测量 |
|---|---|
| 出现高度 | 基底 Z=0.30 mm |
| 名义料线外边界 | X=22.420…49.159，Y=50.902…52.687 mm |
| 尺寸／料线扫掠面积 | 约 26.739×1.785 mm／46.014 mm² |
| 与同层其他基底块最短距离 | 0.804 mm，完全分离 |
| 与后续四层筏层 XY 覆盖相交 | 全部为 0；最短距离约 1.504 mm |
| 与前三个模型层 XY 覆盖相交 | 全部为 0；最短距离约 1.486…1.549 mm |

这些是实际挤出路径按标注线宽作圆形扫掠的几何估计，不是材料实测。后续筏层完全不接触这条带，因此它没有形成从基底到上层的承托连接。

历史原始轮廓捕获中，基底在分块前是一个连通区域；此长带完全包含于原基底外扩区，但不在任何上层的原始筏层轮廓里。水平切缝将外扩边缘切成了独立条。
08:18 旧 G-code 同一区域已存在相同边界的长带（当时路径不连续，料线覆盖面积约 32.273 mm²）；本次墙线连续性修正使其更完整，未解决其无承托用途的问题。

## 2. 当前算法为什么会保留

- `RaftGeometry.cpp` 逐物理层独立做轮廓预处理和分块，没有跨层的承托关系判断。
- `prepare_raft_path_regions()` 筛除的是小面积且小跨度的中心线分量。此长条跨度约 27 mm，不属于该筛选范围；不能为了这一个样本把所有长窄区都删除，否则会伤及有效窄脚／薄片筏层。
- `RaftMerge.cpp` 在路径生成后，仅把无挤出的轮廓从元数据省略。长带可以生成墙线，所以通过该检查及平台、切缝和冲突检查。

因此「可生成路径」和「没有越界」不足以证明该分块有承托作用。67 个筏层用例的通过仍然有效，但不是这项新识别问题已经解决的证明。

## 3. 与 Xmaker 的差异不能混为一项

使用此前已解析的用户 Xmaker `dragon (2).gcode`，按对应资源及出料量印证的基底／中间线宽 1.6／0.8 mm 检查：基底为 5 个连通块，每块都与上层中间料线覆盖相交，没有本次这种基底孤立条。
这只证明该参考样本的输出，不证明 Xmaker 内部一定实现了“孤岛清理”，也不是相同参数、相同床面下的算法对照。

| 项目 | 本次 Orca 项目 | Xmaker 参考文件／对应本机资源 |
|---|---|---|
| 平滑半径 | 0 mm | 5 mm |
| 基底实际线宽 | 0.6 mm | 1.6 mm |
| 基底墙圈数 | 4 | 1 |
| 顶部墙圈数 | 0 | 1 |
| 基底／中间／顶部外扩 | 3／1／1 mm | 10／7.5／5 mm |
| 轮廓和路径来源 | Orca 支撑接触区／阶段生成，再接公共分块与原墙／填充助手 | 参考引擎自己的轮廓、墙、填充及分块流程 |

Orca 当前复用了 `generate_raft_base()` 的支撑接触轮廓和相对外扩；公共分块入口接收的是这些已生成的 `raft_outline`。公开 CuraEngine 的 `Raft::generate()` 则从第 0 层轮廓（包含支撑）分别按三阶段外扩后整理。不能仅因为参数名都叫 CuraV1，就假设上游输入轮廓相同。

已有逆向分析还确认：参考顶部预内缩采用中间层线宽，局部尖角连接参数与 Orca 也不同。这些对齐工作尚未落地；详见 `xmaker_raft_deep_review_20260921.md`。它们不是本长条的已证明唯一原因。
当前模型的 101 mm 床面也不能直接使用参考的大外扩配置作出等价承诺。提高平滑可能改变此长条，但不能把换参数当作承托关系缺陷的通用解决。

## 4. 建议的最小下一步（尚未编码）

优先补“分块后孤立基底分量”的判定，依据承托关系而非继续放大面积／长度删除阈值：

1. 在现有试用分支的整组候选中，识别分块后首层基底的连通分量；原正常外扩边缘如果仍连着有用基底，不作为独立残留删除。
2. 只有完全孤立、与后续筏层及模型接触需求均无关系的分量才可省略；判断使用轮廓与可打印路径证据，不把稀疏填充单条线的间隔当成无承托。层数不足或关系不确定时保留。
3. 将被删除分量同时从墙、填充和输出轮廓移除，再走现有平台／切缝／混摆校验；不填回切缝、不改变参数或模型位置。
4. 回归至少包含本次长带、有承托的同尺寸窄条、小模型原岛、仍连接主体的基底外扩边、多基底层／零中间层及合并后重切。实际验证需要重新构建，不能复用本次 67 用例数字。

完整的多层承托连通图和参考引擎轮廓入口统一，是更大的后续设计；先不要混入这项局部修正。另用受控工艺对照区分平滑／外扩／线宽与轮廓生成的影响，再评价接近 Xmaker 的程度。
