## 最初的切层复核方案（已被用户最新约束替代，未实现）

1. **合成真实输入**：使用模型落床／缩放／旋转、层高曲线、喷嘴、区域／对象覆盖、XY补偿、多材料边界等实际结果。只读 OBJ 的静态尺寸无法回答同一模型换喷嘴／缩放后是否丢字。
2. **截面快速筛查**：在最终切层区域上找细岛、细颈、局部细笔画和骤增的新区域；使用局部宽度／开运算残差得到候选。必须覆盖实际层计划，本样本文字仅两层，固定每N层采样会漏检。规则不依赖 OCR，也可覆盖细线图案和小筋条。
3. **真实生成器复核**：只对疑似层／邻接上下文调用两种真实墙生成器，比较候选邻域中墙、thin_fills／gap fill等能贡献的覆盖和连接情况。不能将尚待填充的普通实心内部面积全部算成墙丢失；多材料区域按实际归属处理。
4. **局部而非全模型评分**：观察消失的连通分量、长笔画中轴连续性、局部未覆盖面积及跨层持续性。即使丢字面积占整块牌子很小，也不能稀释成“全模型损失不到1%所以通过”。相邻层是证据，但单层真实浮雕不能被硬性的“两层以上”条件忽略。
5. **验证 Arachne 的实际收益**：经典墙有明显损失，且 Arachne 确实恢复长笔画／连通性，同时没有明显封孔或过度加宽，才选择 Arachne。若两者都无法保留，输出“特征低于当前工艺能力／需检查几何”的独立结果；不能切换后就报问题解决。
6. **按对象固定选择**：首版统一切换该对象，避免每层来回切换造成表面和过渡差异。后台工作流与 CLI 共用同一核心结果。建议提供 Auto／Classic／Arachne 语义：Auto 执行选择，显式指定另两种时尊重用户；保存请求模式与本次生效结果，不偷偷改公共预设。
7. **缓存与可解释结果**：键至少包含几何内容、变换、实际层位、喷嘴和相关有效配置；更改尺寸／喷嘴／薄壁设置必须重新判断。报告对象ID、风险层／局部包围盒、典型宽度、两种算法的局部损失、选择原因和未解决项。取消／超时／不支持模式输出未完成或不适用，不冒充检测通过。

不建议现在硬编码“厚度小于0.4就切换”或单一全模型面积阈值。候选筛查可先用线宽比例、明显消失的长笔画等规则；最终阈值必须用真实生成器与多类夹具标定，至少包括窄矩形、尖角、孔洞、凹字、凸字、细高墙、0.2／0.4／0.6喷嘴、缩放、多材料和合法单层细节。经典墙开启薄壁检测也应作为对照，避免重复解决已由有效配置覆盖的问题。

### 实现位置与规则

- **Python：外部切片服务的首版优先。** 可用 NumPy／Trimesh 读取几何（关闭自动修改／修复），用 Shapely 等计算分析用投影区域；接收实际实例变换、喷嘴和墙线宽，返回是否存在细特征风险及参数建议。原模型照常交给 Orca，业务端只覆盖 `wall_generator`。是否需要常驻进程及实际运行时延应实测，未作性能承诺。
- **Blender：不需要作为依赖。** 该输入已是网格，无需修改文字对象、执行建模操作或启动场景；新增 Blender 不能自动获得比同一原始几何更多的打印参数信息。
- **Orca：负责按选定参数正常切片。** 外部流程首版无需修改墙生成器。若要求原生 GUI／CLI 都内置自动选择，则将同一规则放在两端共用的导入／有效配置阶段，仍不调用切层；外部 Python 原型不等于原生 GUI 已有此功能。

建议检测流程：

1. 按实际毫米尺寸、缩放及打印朝向只读解释模型；不输出变换后的模型副本。
2. 第一阶段限定平面／近似平面的凸字、浮雕和细线图案：按法向、共面距离及空间邻近寻找表面簇，提取其轮廓并测局部笔画宽度。不能仅使用整个模型最小三维厚度，因为浮雕高度与笔画宽度是不同方向。
3. 统计有一定延伸长度的窄笔画、窄区域占局部特征的比例；排除单个尖角、小三角形及重复面造成的伪薄特征。将宽度与当前有效线宽比较，并考虑经典墙薄壁检测是否启用；不用全模型总面积稀释文字风险。
4. 命中细特征风险时仅输出／应用 `wall_generator=arachne`，其他墙参数、层高、支撑、模型与预设文件保持原值。输入已经是Arachne时无需改动。首版不支持的模式（如现有螺旋模式不会使用Arachne）应有明确结果，避免参数改了但实际不生效。
5. 无匹配风险或超出检测范围时保留原墙参数，并区分“未命中”与“未能判断”。不生成“模型安全”或“全部细节已恢复”的结论。更换尺度／摆放／有效墙参数后重新评估。

本样本中间字有连续0.35～0.37 mm笔画，相对0.42 mm外墙属于明确风险候选；仍需用不同字体、尖角、凹字、曲面字和缩放样本标定规则。面投影首版不宣称覆盖所有三维薄壁、曲面雕刻和隐蔽细节。

### 两种墙方式仍可能丢弃细节的条件（源码补充）

- 经典墙开启薄壁检测时，`PerimeterGenerator.cpp` 的薄壁候选先以喷嘴直径/3为最小宽度做开运算，再提取中轴。0.4 mm喷嘴对应约0.133 mm，这是该候选分支的过滤尺度，不能当作所有形状必然保留的保证。
- `ExPolygon.cpp::medial_axis` 还会删除带真实端点、长度小于 `2 * max_w` 的骨架线；`max_w` 是本次区域返回的所有骨架线的最大宽度，并非每条线自己的最小宽度。细短笔画／小点即使超过宽度门槛，也可能在此被删除。
- Arachne 的 `WideningBeadingStrategy` 对小于 `min_feature_size` 的局部厚度可给出0条线。当前0.4 mm喷嘴、25%最小特征为0.10 mm；85%的0.34 mm是最小输出墙宽，不是细节删除门槛。达到最小特征但小于最小输出墙宽的候选可以被加宽，仍受其他步骤影响。
- `WallToolPaths::removeSmallLines` 只过滤非闭合、奇数中心墙：普通层门槛为该路径最小实际线宽乘 `min_length_factor`，首／末模型层为线宽的一半。当前系数0.5，若路径最小线宽0.36 mm，长度门槛约0.18 mm；不将此公式套到所有闭合外墙或所有短G-code线段。
- Arachne 生成前还简化轮廓、移除退化顶点和小面积外轮廓，小独立点／尖角可能在生成墙前消失。两种方式均只能使用有效切层区域：若微浅浮雕未被实际层面采到，或区域此前已因补偿／几何问题消失，墙算法不能恢复未传入的特征。

这些条件说明非切片预检需要同时考虑局部宽度、延伸长度与孤立小区域，不能只比较笔画宽度与0.42 mm；本补充只读源码，未改变既定“不切片、不处理模型、只选择墙参数”的检测边界。

## 2026-10-17：可编辑模型的预防方案

- 对固定带细文字的模板，建议直接采用经过验证的 Arachne 工艺模板，不必每次猜测经典墙是否会丢字；几何预检继续判断模板内是否出现更细、短、浅或间隙过窄的新特征。通用模型仍可保留原有按风险选墙方案。
- 当前样本的候选参数保持喷嘴0.4 mm、最小特征25%（0.10 mm）、最小墙宽85%（0.34 mm）、短墙系数0.5，仅将墙生成器改为Arachne。连续横笔0.35～0.37 mm不需要仅为跨过0.10 mm门槛而进一步降低最小特征参数；这不等于已验证所有细节恢复。文字凸起0.4 mm在原G-code已有两层，降低层高不能代替XY细笔画处理。
- 对后续可编辑的平面浮雕文字，可把有效笔画宽0.45～0.50 mm、需要保留的间隙0.4～0.5 mm、凸起高度0.4～0.6 mm作为0.4喷嘴/0.2层高的初始设计目标。这是有余量的工程起点，不是Orca硬阈值或所有字体/材料的保证；尖端、小点、短横、凹槽和最终缩放仍需独立检查。加粗笔画时必须同时检查字内空隙和字间距。
- 保留可编辑文字/曲线/CAD源参数；在源端调整字体、字号、笔画、间距和凸起高度。导出结果须有真实实体几何、正确尺度及合法拓扑。当前提供的是OBJ网格，不能假设其中仍含原始文字对象或字体参数。
- 工具分工：已有Blender/其他编辑器负责源模型参数约束；Python可在导出前或服务端只读测量最终几何、给出风险和墙参数建议；Orca按有效参数正常切片。若仅允许换墙参数，超出工艺能力或几何无效的输入应报告“仍有风险/无法判断”，不能通过切换Arachne宣称解决。
- 不切片的几何规则能降低风险，不能证明任意模型的全部最终挤出路径都保留。方案仍未实施，未执行新切片、GUI或实物验证；本轮仅追加分析记录，无需应用构建。
