## 原因与范围

用户日志中的 100 × 100 × 0.24 mm 薄片在 101 mm 平台上受排布边界／占地约束无法排入。
Linux 既有排布搜索仍应用失败候选的旋转，JSON 居中投影保留了约 135° 的旋转，显示外接尺寸约 141 mm。
本任务按用户指定处理第一项：JSON 保留有效输入姿态和已完成的自动定向，不返回失败搜索附带的旋转。

仅在请求多盘变换 JSON 且确实进入排布时，按实例身份保存排布前变换；复制重试不覆盖旧快照。
仅盘外实例采用快照，继续每个实例一个独立虚拟盘、XY 床面中心、Z=0。
正常盘内、显式单盘、不排布导出的姿态、现有 JSON 字段与失败语义保持。
GUI 不提供该 JSON 接口；不修改共享排布算法、GUI、模型实例、物理盘、3MF 或切片。
服务端与客户端字段协议不变；历史单盘操作和客户端坐标显示问题不在此任务范围。
