## 职责与边界

`test_extrusion_entity.cpp`的`[VariableWidth]`以段长×两端宽度均值×层高为非桥接体积真值，验证末组与中间组一致；检查正反方向、3层高/3角色、合并/拆分、常宽/窄正宽及闭环身份，不靠报表面积减少判定通过。对应`VariableWidth.cpp`共享转换可能影响Classic细墙及填充，仍须配套`[Fill]/[Arachne]`、CLI和最终G-code检查；模型实际可打印性另验。

其中`[WidthGrouping]`补新组收窄后变宽/变宽后收窄、共享点宽度不连续、恰好0.05 mm、常宽5类，逐组检查完整宽度范围、局部积分体积、连通性及全长。另一用例验证折线正反向分段保留所有原拐点和中心线（插值容许每坐标一个整数单位舍入），不允许跨弯快捷连接。最终G-code仍会经历现有resolution简化，需单列该阶段的双向路径偏差，不能把分段增加误报为路径丢失，也不能跳过实际正E/孔交叠核查。

`test_cli_fixed_position_slice.py` 在 master 的固定位置/单多盘/禁用盘/3MF验证上补6个报告交叉场景，复用 `test_cli_slice_analysis.py` 的严格JSON和G-code解析；成功场景逐条比较报告开启/关闭的执行指令、有效配置和层数，仅实际成功盘生成对应报告；越界及全禁用失败不生成报告。两脚本身份均写入证据，运行结论以当前合并源码为准。

阶段报告新增两个 `[ModelStageReport]` 原生用例：二进制／ASCII STL 精确共享顶点，同时保持文件哈希、面数、逐面坐标与顺序，且相邻浮点坐标不合并；百万面用例实际写出并回读 1,000,012 面，旧表示因 3,000,036 个顶点触发截面预算，新表示 501,509 个顶点可完成指定截面。该用例不是百万面完整高级修复压测。Linux 配置回归另使用真实系统 `FindZLIB` 验证 ON 默认共享库被拒、ON 显式静态通过、OFF 默认不受影响，并核对工作流实际参数；不能再以未创建 ZLIB target 的适配器探针代表完整 Orca 配置。当前构建与运行结果见[实施记录](../validation/2026-10-18-slice-analysis.md)。

`[AnalysisCollection]` 以默认/显式false/true的解析器实例对照线段、圆弧、长规划队列和文件导入：关闭时报告元数据为空且未知；开启时有数据；原耗材/估时/预览字段逐项一致。reset 清除材料与阈值数据但保持实例采集开关，已有报告测试显式启用。角色运动观察器和额外G1空移距离已删除，所有move的travel_dist均纳入开关一致性比较；圆弧与挤出距离原有语义不变。运行与GUI状态见本轮实施记录，不用测试存在代替执行。

`estimated_flow_cap_distance` 新原生真值覆盖三角/梯形部分超限、严格等于 float 峰值、只有加速/减速、恒速/零加速度、零倍率、每材料上限及倍率快照、短向量默认规则、缺失/改变上限、未参与/残留块、圆弧/螺旋与长规划队列。Python/Web 独立验证参与长度、超限长度和比例的零/未知/不适用合同，不把峰值观察的有效性与新块绑定；运行状态以实施记录为准。




三维精确集合、跨层未覆盖体积及角色运动的旧专属用例已随功能删除；历史验证与数值案例留在[实施记录](../validation/2026-10-18-slice-analysis.md)，不作为当前输出合同。保留指标仍逐值对照旧报告，不以浮点容差隐藏变化。

Web全局对比保留材料唯一身份、乱序/重复、不同cap/冷却阈值、零/未知、失败/历史和核心CSV验证；不再要求已退役角色/加速度/质量明细。真实报告对照逐值校验native原值与B−A，不把页面夹具当业务E2E。CSV按钮实际浏览器下载另验。

本模块负责测试基础设施与维护工具。归属以[模块清单](../modules.json)的 `test-tools` 为准。

## 核心流程

`[ResidualIsland]`新增2项原生回归，先复现共享端点薄墙被跨缝拼成折返后简化消失，再验证仅总退化场景恢复正E可用路径；覆盖8种片段排列方向、原宽度/总长、非接触和普通/零宽路径不变、短线过滤和0墙圈保留。与[Arachne]/[Fill]/[SliceAnalysis]/[GCode]及40次特征CLI一起验证。具体运行身份/结果和真实模型对照见本轮实施记录，不以fixture替代GUI/实印。

`[ResidualRisk]` 确定性验证同段宽高不拼接全局极值、等宽高边界、桥接不适用和非法行未知；残余峰值区分分区轮廓保留/缺失、孔交叠的墙/补缝/桥接/混合来源，并核对输入路径不变及非峰值层非法。Python/Web验证真实首个峰值身份、分类和、配对范围及计数/长度，旧报告不编造证据。实际模型47/89层与首层细补缝的定位、原92项/Web272项/Python88项、40次特征切片和性能证据见实施记录，不将其计为实印通过。

`[SolidGapPeak]` 为只读报告增加2个确定性用例，分别验证跨区域同类去重、跨类重叠单列、部分路径覆盖、稀疏内部排除、真正峰值层，以及空模型/完整零/非峰值层非法的未知语义。Python验证器可兼容缺摘要旧报告；摘要存在时必须与所有层的实际最大值/首个峰值层/Z一致、互斥类别之和相符，不能因新增而放宽旧逐层字段。Web独立验证来源绑定、异常隔离和按类别检查参数，不把桥接规划证据算成几何承托结论。运行/身份与性能对照见本轮实施记录。

用户本轮授权后，流量观察补上真实支撑指令的端点舍入回归（3个cap输入先红后绿）；容差仅针对两次float运算的端点副本，不改规划/指令/估时。新增 `quality_paths` 合同校验实际材料/角色、正E路径长度、速度/风扇/名义宽高范围、独立异常隔离，真实解析器核对M106和圆弧长度。空报告为新增空rows，不恢复退休的角色运动观察器；旧流量不完整兼容与缺字段未知继续保留。当前88项原生、83项Python合同、40组特征及固定位置/分盘回归结果和程序身份见[实施记录](../validation/2026-10-18-slice-analysis.md)。

`test_slice_analysis.cpp` 的 `[SliceAnalysis]` 定向校验只读切片指标；`scripts/test_cli_slice_analysis.py` 对已构建应用在新隔离目录比较报告默认/显式关闭/开启，核对可执行 G-code、有效配置、旧结果不变，以及报告存在性、非法组合和已有文件保护。新增独立模型路径优化四种组合及非法/切片缓存组合，共17场景：默认及显式关闭仍与原控制组同指令；显式开启允许修正路径，但开启模式内部的报告开关必须保持全部指令/旧结果一致，跨模式完整有效配置不变。原生`[DetailPathOptIn]`冻结旧分组和末组体积、验证CLI默认false且不属于PrintConfig、固定位置小方块在模式切换时清理切片缓存；不依赖无关的InfiniteBed自动摆盘。资源可显式指定，不下载、不构建、不打印。真实结果见[实施记录](../validation/2026-10-18-slice-analysis.md)。

核心指标精简删除了三维精确连通、深度、源面/体积、跨层投影及坐标数组的专属测试和验证器，因对应生产计算已停止，不是放宽其正确性断言。第二轮同时移除无消费者的角色运动、名义流量范围、独立顶/底差集、逐层时长及重复底面统计专属验证。混合测试保留二维面积、无路径岛、闭孔覆盖、窄宽/间距、整盘床面面积、流量/冷却、配置/几何不变与取消；新增报告不得携带废弃字段的反向合同。接缝不再计数，但处理器原预览坐标不变仍有验证。40组CLI模型和工艺配置保留，桥接/支撑改从最终G-code的TYPE和正E空间运动独立核对（弧只核存在，不以弦长估计弧长），耗材与筏层实际层位另验；不依赖已删除的角色报告统计。

冷却观察仍覆盖多材料独立分母、同时间/同Z不合并、禁用/0/无用料不适用、缺身份未知、复制/reset与原估时不变；区域内第17次真实路径offset触发取消的直接/嵌套用例保留。Python反向断言检查退休的group/逐层字段、bed区域数组、seam坐标，即使空数组或null也不允许当前产物继续生成。实际通过计数不沿用精简前历史数量。

包围盒裁剪优化有同一 Print 内完整未剪枝参考回归，含远隔多岛/带孔/嵌套岛/交叉路径/盒接触与反转输入。复杂 1828500 面龙模型检查报告开关前后可执行指令和有效配置一致，单独记录整报告耗时；与源码、测试和二进制 SHA 绑定，不把历史构建当新代码验证。


`scripts/test_cli_slice_features.py` 生成闭合共享网格的细笔画/通孔/分离部件/稀疏内部/低密度顶面夹具，分别执行 Classic/Arachne，确认有效工艺仅墙生成器不同；验证逐层计划路径指标，并对已知直线细笔画核对最终 G-code 挤出层。夹具解析器不是通用 G-code 覆盖算法，遇不支持的挤出圆弧会失败而不猜弦长。脚本单测验证闭合、确定性和最终指令判据；测试资源/二进制/仓库 result.json 前后哈希不变，证据写独立新目录。原生用例补多区域/孔内岛/实体目标/非法及取消、弧长、底部离床和多材料流量 cap，不新增业务阈值。
