## 职责与边界

本模块负责G-code 解析、统计与预览。归属以[模块清单](../modules.json)的 `gcode-preview` 为准。

新增 `estimated_flow_cap_distance` 与原名义流量和同块峰值独立：按普通估时器已定型块的加速、匀速、减速阶段计算超过材料配置上限的距离，再除以同口径参与路径总长。使用块创建时的线性 E/M221 体积、定型峰值和阶段距离，不把峰值超限的整段全算超限，不读取未回存的 exit 速度；等于配置上限严格记为未超过。有效零倍率路径计入总长但超限为零，无参与路径为 0/0/比例 null。cap 缺失、非法、计算与报告的 cap 身份不一致或不支持/残留未估算块仅使对应新材料块未知。元数据随 reset、复制和 finalize 清空/赋值同步；不改变原估时、G-code 或配置，不代表实机流量和物理质量。

## 入口与调用

报告统计按需采集：CLI 将现有 `slice_analysis_requested` 传到 `Print::export_gcode` 末尾默认false的内部参数，再通过 `GCode(bool)` 构造 `GCodeProcessor(bool)`。实例内用途固定，reset 清空数据但保留开关；GUI后台导出、独立G-code预览和普通CLI均默认关闭。不启用时不建立分析角色vector/材料cap map，不填充每层用料、块快照，不计算峰值或超cap距离；原运动规划、耗材、估时、M73后处理继续工作。固定字段和少量分支仍存在，不宣称完全零内存/零开销。

- [GCodeReader.cpp](../../../src/libslic3r/GCodeReader.cpp)：`GCodeReader::parse_file` 逐行解析并维护坐标状态，通过回调交给调用方。
- [GCodeProcessor.cpp](../../../src/libslic3r/GCode/GCodeProcessor.cpp)：来源/配置初始化及路径、耗材和时间统计。
- [GCodeViewer.cpp](../../../src/slic3r/GUI/GCodeViewer.cpp)：`GCodeViewer` 把处理后的 MoveVertex 分类为可绘制路径与 GPU 缓冲区，管理可见范围。
- [GUI_Preview.cpp](../../../src/slic3r/GUI/GUI_Preview.cpp)：`Preview`／`View3D` 连接工作台、画布和预览控件；切换盘及层范围时刷新显示。

## 核心流程

`SliceAnalysis.cpp/.hpp` 的 `make_slice_analysis_report` 只读本次切片的 Print 与 GCodeProcessorResult，按源对象/切片组/实例区分计数，记录模型层、支撑层、首模型层截面及 G-code 聚合指标；不会再次切片、修改配置或判断可打印性。首模型层截面不是直接接地面积，G-code 层时长不是局部冷却时间，指令流量不是实测出料量。数据未测/无样本与零值区分，数值范围记录无效样本数。对象与区域设置单独列出，不把全局配置冒充全部有效值。报告只在显式 CLI 导出调用，GUI 普通预览/统计不进入该路径。

`extrusion_by_role` 按处理器已有角色区分外墙、填充、支撑和自定义预挤出；全角色范围仍保留，但不能用其中的自定义挤出宽高判断模型尺寸。首批不输出内部 `PrintObject::size()` 缓存尺寸，避免同源对象不同缩放组误报；也不宣称局部厚度、孔缝、桥接安全分析已完成。

`cross_layer_geometry` 复用逐层 `lslices` 合并结果，按单实例记录真实采样 `slice_z`、打印 Z/层高、前层身份与间隙，以及相邻模型截面的重叠/超出面积、无正面积重叠的完整岛数量和面积。首模型层为不适用（比较值 null、complete=false）；切片错误、非有限或不递增层序不误报完整。间隙保留正负号，合法 Cura V1 首/第二模型层重叠不因负间隙而被拒绝；这不改变垫层排层或模型首层参数归属。平面投影不证明实际承托，支撑/筏层不进入此几何比较。

`source_volume_sampling` 仅对文件中已有正向源体积，记录按切片器 float 变换得到的 Z 范围、保留模型层采样面在范围内部/边界的数量。复用全层 `firstLayerObjSlice()` 缓存统计源截面、与最终模型区域相交、该位置有计划路径的层数，不重切、不按包围盒猜路径。缓存允许被裁掉的尾部空层，共享对象按已有同序体积关系找到 owner；缓存缺失/过短或层/路径无效时后三项未知，无层不填零。范围有采样不等于切到实体，有路径不等于该体积独占路径或完整保留；合并 STL 的局部文字/浮雕未自动识别，负体积和修改器不作为统计目标。

`planned_bridge_paths` 在同一次路径递归中分别收集 `bridge_infill`、`internal_bridge_infill`、`overhang_perimeter` 的有效片段数、计划折线总长和逐层足迹面积之和。各层先独立 union 再相加，不能跨 Z 合并；片段数不是桥数量，总长不是跨度。缺失/非法路径不当作 0 或已通过，三角色不借 `is_bridge()` 混算。报告只读共享数据，不修改 GUI/CLI 原生切片；Compare Web 仅分组展示，不自动择优或新增跨层差值。测试与实际运行状态见实施记录。

`planned_layer_coverage` 按切片组、单实例、模型层读取墙和填充的宽度偏移多边形，记录截面覆盖、完全无路径区域、孔区侵入及配置后实体/顶/底表面未覆盖面积。合并截面并排除孔中独立材料岛，不重复统计已复制到 fills 的 thin_fills；稀疏内部不算实体填充目标，降低顶/底面密度留下的有意空隙仍是未覆盖面积而非缺陷。无挤出/零流量路径排除；非法路径标 incomplete 并输出 null，不用部分结果冒充完整。上述足迹在 G-code 接缝裁切、螺旋等导出变换前，不是实际材料覆盖或三维连接/孔缝合格证明。

逐层再记录目标岛数量、岛内计划覆盖分多块的岛数、同一完整计划覆盖块跨多个目标岛的块数，以及闭孔负空间总数、被完全占据/剩余分多块的数量。岛内判断先裁到岛，跨岛判断保留跨缝足迹；孔内实体先排除。统计只计算正面积区域，不把边/点接触计为跨岛覆盖，不引入任意面积阈值。覆盖完整性同时检查层几何与路径，失败时六项全部 null。普通稀疏填充也可能多块；这些计数不是断裂/粘连/三维堵孔判断。Web 各组按单实例分别取单层最大值，不跨层累加成部件/孔数，也不新增自动择优或 A/B 字段。

`nominal_target_path_connectivity` 是独立的三维名义观察，不改上述二维口径。目标T来自当前补偿后的region slices与模型层厚，不能替用象脚层保留的未补偿lslices；模型路径M复用同次足迹及各path自身高度，保留目标外材料。按1e-6mm Z事件扫描T、M和交集C的空间连接；同高度共边合并、仅点触分开，跨高度需要正面积XY相交，线/点接触及真实Z空隙不连接。每目标输出实际体积、C的连通块数和T\\M未覆盖区域的实际体积/XYZ范围，完整M关联多个T时另列跨目标连接。XYZ为组局部XY与打印Z，单实例、不含支撑/筏或跨对象关系。无保留层/非法数据整新块unknown，合法空为[]；新块由对象出口显式搬运。

D的差集不能继续使用整数交点：真实窄区已复现原始diff_ex面积大于目标，且仅检查D≤T不能排除未越界的舍入偏差。源region自身也可能有交叉闭合轮廓，因此本新块的T/M归并、C/D及跨Z相交统一使用`SliceAnalysisGeometry`的CGAL/EPECK精确NonZero集合，不再保留另一套严格PWH入口。每个Surface分别按NonZero外环减去各显式孔的NonZero集合解释，再合并Surface；每条path原宽度轮廓作为一个NonZero组，独立path再并集，不能将所有path的有向环混算而相互抵消。路径缓存只附加原数组中的每path范围，不重复offset；不改源轮廓和既有其他报告的整数布尔口径。

读取arrangement的正面积内部面而非合并点触面的PWH扫描结果；每个Region仅保留自身精确边界。批量来源入口保持每个Surface/path独立解释，平衡二路精确join后才统一测量和提取Region，不先测量/重建随后被并集丢弃的中间组件。路径整数环副本只暂存当前层，不重复offset或新增全模型缓存。跨Z连接先检查边界顶点/精确中点是否严格位于另一集合内部：命中已能证明正面积重叠；边界接触、孔内或未命中仍执行原精确do_intersect，不将少量见证点当完整阴性判断。M/C只用于连通关系，不再累计没有消费者的体积；T及未覆盖D的面积、XY范围和跨Z体积仍保留有理数，直到JSON才换算mm³/mm。空差集/单集合复用不可变Shape，后续布尔先拷贝几何，不写回源；不回整点、不截断、不以容差删除微小正区域。

未覆盖D的最终体积按DSU最终目标根归组，对既有Missing记录的体积作二分精确求和，避免大量小分数逐次加入越来越大的有理数。事件扫描完成后Missing不再增删，临时分组只持有稳定体积指针，不复制一套区域或添加缓存生命周期。每条明细的顺序、体积及范围检查保持，汇总仍先做精确D≤T比较，再沿原函数转JSON数值；递归入口和合并前检查取消。T体积与几何连接算法不因该汇总调整而改变。

已求得精确交集C为空的材料候选不再送入D差集：点/边接触或包围盒相交但实际不交，均不能移除T的正面积。C跨Z候选先检查其T/M父节点当前连通根；当前事件的T/M跨Z连接已完成，不同父根可以排除C连接，同父根仍必须通过原精确正面积判断。直接复用每个C节点已有的一条Association，不缓存会变化的根、不复制父关系、不修改有效候选顺序。

AABB浮点范围必须向外包含精确边界，仅筛选候选，最终仍作精确相交。无效层/高度或正宽度无法表示为不同JSON double边界时保留局部未知；helper内部一致性异常沿既有CLI报告失败路径返回错误并保留G-code，不伪装成正常未知。取消在点/孔/候选及阶段边界检查，单次CGAL操作内部不保证立即中断。这是既有名义截面/路径边界上的集合精算，不反推原网格真形状、实际挤出或物理融合；宽度offset输入及Z量化仍为既有口径。旧字段数值隔离不代表整份报告运行隔离：显式报告的新块未算完时，旧字段也尚未写出；默认关闭和GUI不承担此计算。复杂模型、构建身份及回归结果见实施记录，不能用正常样例通过代替复杂模型验收。

目标内部C多块可能经目标外M绕行连通；正常稀疏填充也计入未覆盖体积，不能直接叫断裂/漏打。区域范围仅定位，不是实际形状或体积计算依据；最终连接不证明此前打印时有承托、熔融结合或实物强度。T随补偿与层高变化，局部序号不用于A/B配对；Web三类明细各20条分页、unknown不补0。该分析只在显式报告路径运行，原生GUI/普通CLI不新增功能入口、阈值或参数覆盖，当前验证状态见实施记录。

开放空白增量仍写同一逐层记录：`planned_enclosed_exterior_region_count` 与 `planned_enclosed_exterior_area_mm2`。`bounded_voids` 复用标准 ExPolygon 孔，排除嵌套材料；从计划足迹有界空白中减去源截面实体和原有闭孔，只保留源截面中原来连通外界的空白部分。数量按包含该正面积部分的计划孔计，每孔一次，不把差集碎片当槽数；面积为这些部分的总面积。不生成围框，不做人工补缝，不用源实体替未打印的墙补成围壁。源闭孔和普通填充内部空白不算新增外界围合，完全填满开口也可能为零；不识别语义槽、最小间隙或三维贯通。不完整层两项 null。Web 新两项单独验完整性，旧报告原六项不受影响，仍无自动择优或 A/B/CSV 增量。

`planned_model_bed_footprint_area_mm2_per_instance` 复用首层计划路径面积，仅底部 Z 在一个坐标单位内贴床时计入；离床为 0，数据不可用为 null，不含支撑/Brim/Raft。G-code 挤出段长/总长使用处理器弧长，不能用首尾弦长或其他角色的距离；接缝单列但仍包含于原 other 计数。逐层时长保留顺序和未知。流量上限按导出器的材料 id/get_at 规则读取，0/缺失/非法为未知，比例包含自定义预挤出且不代表实测能力；非法非有限 cap 的配置快照为 null，正常配置字符串合同保持。

`planned_plate_bed_footprint` 在整板坐标分别并集模型、支撑/筏、Brim 足迹及其总并集。按各 path 的 `print_z-height` 是否在原生坐标单位内贴床判断，不用整个截面冒充材料；共享支撑只使用实际 owner，模型/支撑按实例 shift，Brim 已是整板坐标不再变换。不含 Skirt、擦拭、自定义或无挤出/零流量路径。分类面积允许交叠，总面积不是三项相加；非法新块整体 null，已知空为 0，不改变原单实例指标。它不是实物接触面积或附着评分。

同块新增 `model_regions`、`support_and_raft_regions`、`brim_regions`、`combined_regions`，各复用上述已有并集，只扫描正面积ExPolygon，输出扣孔后的 `area_mm2` 及 `bounds_mm.min/max`（世界XY毫米，包含plate origin）。洞内独立材料岛另列，空类别为[]、整块未知为null；旧四面积和scope/complete保持，不增加路径扩张或union。范围框不是最小局部宽度，数组顺序不作跨候选匹配身份。

Compare当前另有独立全局差值表和CSV，覆盖整板面积、空移、逐材料定型流量/冷却、按角色运动与耗时用料；沿用同输入/机料/修复门禁。材料与角色按唯一身份对应，比例差为百分点，阈值不同只限制相关差值；不混配逐层/底面/连通区域。下方各历史增量的“不增加A/B”指该局部观察不进入原10项差值，并不禁止此独立全局表；没有自动评分、改参或选择。

`planned_perimeter_loops` 统计原模型 perimeters 中闭合 ExtrusionLoop 的完整中心线周长与路径方向转角。递归 collection，要求每片均为墙、片段连续且整体闭合；连续重复点不重复计角。转向 0° 为直行、180° 为折返，不是内角或曲率。开放墙/多段路径、缝隙填充及支撑不冒充闭合环；无环 complete=true/count=0/range=null，适用但损坏的环使新块未知。单实例统计不乘实例数。报告补相关对象加速度与区域小轮廓速度配置原值，不将 0/% 等配置约定解释为实际运动值。

`solid_fill_target_depth` 读取原 fill_surfaces 的 `is_solid()` 目标，使用每个 Surface 的有效厚度与 print_z 建立名义 slab；合并层取显式 thickness，不按固定层高乘层数。以原生坐标单位量化 Z，通过正反向事件扫描在固定 XY 追踪连续区间，重叠不重复，真实间隙中断，不能把横向漂移交叠链当连续深度。顶/底目标按同高度并集后累计面积，深度分别取正面积目标内最小/最大。无目标面积 0/范围 null；无层或非法输入整新块未知，不污染旧覆盖。不是实物密实厚度、有效实体层数或封顶跨度，低密度/桥接流量不改变名义目标意义。最坏复杂几何仍可能有较高布尔运算成本，循环检查取消，保留基准数据而非承诺线性复杂度。

`planned_material_depth` 在同一目标位置另查已生成的模型墙/填充路径。复用 footprint 遍历的宽度足迹，按路径自身 height 聚合名义 slab；单一高度直接复用该层 covered 并集。模型和支撑由 `LayerPathCache` 按实际 Layer 指针共享足迹/高度缓存，贴床统计仍独立。材料 slab 先建立共用的 Z 区间并集缓存，再从各顶/底目标沿固定 XY 连续求交，遇到空隙即停止，不建立全盘历史深度分区；原填充目标深度算法独立保留。合法未覆盖目标明确记为零深度，并报告起点未覆盖面积；无目标 area=0、range=null，非法路径高度仅使新块未知，不污染旧覆盖/目标深度。按各目标高度累计、单实例、重叠不叠加厚度。它不是挤出线圆角/熔融结合、实际密实厚度或强度，也不含 G-code 导出阶段改动。对象报告出口必须显式搬运新块，不能只在内部计算中生成。

`joint_lower_path_slab_coverage` 按实例、模型层、路径自己的量化底面分别记录目标足迹与未覆盖面积。仅查询 raw `source.print_z < current.print_z` 的模型/支撑/筏路径，要求名义块 `source.bottom < target.bottom <= source.top`；Z 分辨率为原生 1e-6 mm，真实一单位间隙不算接触，同源打印Z不借浮点容差混入。全板实例平移后联合去重，读取当前筏owner而非backup；每Layer只扩展一次路径宽度，按源Z/目标底面缓存联合区域与边界。外桥另测同一联合区域内连续空段，保留同路径片段前后有覆盖的子集，不把不同片段拼接。面积和桥检查独立；非法目标高度使整层底面未知，可能影响某底面的源非法只污染该底面；空路径完整但无底面，无桥空段为0/最大值null。它不含床，不证明真实接触、打印时序、两端锚定强度或不可桥接，更不自动判失败。旧相邻层/支撑XY投影字段不替换。路径递归和每path入口检查取消，避免单region密集路径拖延取消；层缓存与联合区域仍有内存和布尔运算成本，不能以缓存复用次数代表复杂模型性能。

复杂报告的岛/孔裁剪先用缓存的精确包围盒排除必不相交的完整多边形，再执行原布尔操作；接触盒保留，轮廓/孔及相对顺序保留，不改变精度或按独立交集累加面积。同一 Print 的未剪枝参考值作真值回归。报告仍有双向 slab 扫描与复杂 Clipper 成本；开销和跨进程面积尾差见实施记录，不以简单模型测试代替复杂模型成本。

`gcode.travel` 只统计 Travel 记录的 XYZ 距离（包括圆弧和抬Z），不混入擦拭或原地回抽。显式采集分析时G1还保存当前空移XYZ距离，消除Travel携带上一次挤出距离的问题；关闭时维持原来只在Extrude计算该值，GUI目前也只在Extrude分支使用该字段。Extrude原值、G-code生成和估时均不变。无记录为总长0/范围null，非法记录使总长未知。`seam_position_bounds_mm` 是处理器检测到的接缝标记XYZ包围范围，保留负坐标，不是完整空间分布或接缝质量。无标记为完整但不适用，非法标记不输出部分包围范围。

每个 `extrusion_by_role` 增加 `configured_flow_comparison`：每段指令速度×每毫米体积严格大于该段材料配置上限时，累加该段处理器路径长度；比例分母为同角色总挤出长度，不按记录条数，也不把不同材料上限混用。缺少可信上限或非法段使该角色两项未知；已知总长0时长度为0、比例null。浮点/指令舍入造成的微小超出保留为原始观察，不代表实际超流量、出料不良或打印失败。Web独立明细展示，不新增A/B评分或自动选择。

每个角色的 `estimated_motion` 来自 normal 时间估算器本来就会处理的最终运动块：在重算梯形速度后、移除已处理前缀前累计。峰值读取实际梯形的 cruise_feedrate，不读取尚未达到的请求速度；切向加减速仅统计有正长度的加速、匀速、减速阶段，分别为 +a、0、−a。G1/原生圆弧在创建块时标记正向挤出，排除 Travel、回抽、Custom/None；保留队列不重复计数，最终仍未定型的相关角色为未知，不改变估时器处理方式。默认元数据未知，两个 reset 与复制赋值同步；零块为不适用，不输出伪造零范围。它不是全程速度最小值、各轴/向心加速度或实机结果。GUI默认不采集该元数据，未接入自动改参；独立报告按显式 CLI 导出，Web 新明细不进入 A/B/CSV。

每材料的 `estimated_peak_flow` 复用上述 normal 定型块，在创建块时快照材料索引、线性 E 换算的每毫米体积及当时的全局 M221 倍率，消费时乘同一块的实际峰值速度。不能把跨块最大值相乘，也不重复乘已写入 E 的工艺/耗材倍率。按材料独立保留完整性、块数和峰值范围；最终残块只影响所属材料，零倍率对应合法零流量，无块不适用。非法丝径/倍率、体积 E、分工具倍率或英寸模式后的新块未知，不改旧解析器行为；显式 M200 D0 本身不使线性 E 失效，但不会补救此前不支持的模式。reset/复制同步 metadata，缺历史 metadata 为未知。配置流量上限缺失/非法或比例溢出只使比例 null，已知峰值保留。此范围不是全程最小流量、实测出料或材料熔融能力；Web 独立展示，不改原名义流量、A/B/CSV、参数或候选采用。

`seam_positions_mm` 与原接缝计数/包围范围在同一 moves 循环收集，保留处理器预览坐标的全部顺序和重复点，不复制所有 moves。坐标包含打印板/挤出机偏移，不是源模型坐标或实物位置，不能按 Z 反推模型层。空为完整空数组，任一非法点使新数组整体未知，不给出部分“完整”点列。Web 只分页显示，不截断 JSON；不评价接缝好坏。

GCodeProcessor 仅在显式采集分析时，在原 finalize 移动循环、临时 layer ID 被替换为预览 duration 之前，保留 `layer_extruder_ids` 及完整性。只收集正流量/正长度的非 Custom/None Extrude，同序列同材料去重；包括模型、支撑/筏、Brim/Skirt，不按 Z 或相同估时猜身份。两个 reset 实现与自定义复制赋值同步处理；未采集或历史结果默认未知，不能补为已完成零值。额外成本为每层小 vector 和原移动循环中的去重，不增加每个 MoveVertex 字段；普通 GUI/CLI 跳过该采集，旧预览首层扣准备时间、估时、移动和 G-code 不变。

每个实际材料增加 `layer_time_threshold_observation`：按真实材料索引读取现有 `slow_down_for_layer_cooling` / `slow_down_layer_time`，对参与序列的原 normal.layers_times 作严格小于比较，各材料独立分母。同时间的两个序列不能合并；原首序列含准备时间，不等于 CoolingBuffer 的 flush 窗口。禁用、阈值 0 或没有参与序列时不适用；缺身份、非法阈值或相关序列时间未知时不输出部分计数/比例。仅在完整适用且没有低于阈值序列时输出合法 0，不新增冷却阈值、自动降速、评分或择优，也不称冷却不足/调速失败。正常配置序列化保持，非法阈值配置项为 null 而非丢弃整报告。

GCodeReader 解析行，GCodeProcessor 根据来源、配置和指令更新运动、角色、耗材与时间统计；GCodeViewer/GUI_Preview 将结果变成图层滑块和渲染缓存。普通文件通用预览与提取完整 Orca 内嵌配置是不同能力。

`section_min_island_gap_mm` 使用每层合并后的正面积 `lslices` 岛，包含外轮廓、闭边及孔边。每岛建立毫米 double 线段 AABB，逐岛对双向查询全部边界顶点到另一岛线段；包围盒只作下界剪枝，不当作真实间距。因为已归一化岛没有相交内部，双向端点到线段的最小值即岛间边界距离。少于两个岛为不适用 null，coverage 不完整为未知 null，结合已有完整性和岛数区分；点接触的 0 保留。Web 独立校验并取各层最小值，旧八项不受缺字段影响。不跨组/实例测距，不测同岛 U/C 槽、颈宽或三维间隙。象脚层保留未补偿 `lslices`，不能据此评价补偿后的路径间隙或实物公差。

`parallel_boundary_clearance` 使用同层全部归一化岛的原始线段Voronoi图，只取同一岛、严格平行且方向相反的线段站点之间正长度有限主边。材料内和空白内的间距分别取最小；空白可能为闭孔或开放槽。平移到局部中心后仍超出Boost整数域，或原图验证失败，仅本块未知；不使用旋转修复后的图。无适用边为完整/null，不意味着没有薄区（方形及非平行曲颈可能不适用）。这不是通用最小颈宽、三维厚度或补偿后实物间隙，旧岛间距离不变。Web逐项取全部有效层中的最小值；缺层/序号不连续/任一层未知不冒充完整。

## 配置与约束

`external_bridge_projection` 是独立逐模型层观察：仅 `erBridgeInfill` 开放路径，对比前一模型层合并后的计划线宽足迹。沿原折线顺序求内部覆盖区间，排除边界上的正长重叠；相邻未覆盖段跨顶点合并，弯折用中心线弧长，不按裁剪结果顺序或邻近端点跨路径拼接。输出未覆盖段数/最长长度，以及两侧在同一保留路径片段内都有正长覆盖区间的段数/其中最长长度。没有空段为0/null；首层、非法前后层/路径或当前闭合外桥路径为未知null，不影响旧观察。内部桥和悬垂墙不混入本项。

这是 G-code 导出前的计划投影，不是实测跨度或锚定合格率。正常稀疏填充也可能留下空隙，片段边界缺少一侧证据不等于实际无锚；没有使用支撑、同层先后、真实接触或机料能力。Web 按层并列四值，不跨层组合，不增加 A/B/CSV、评分或自动选择。普通 GUI/CLI 未请求报告时不执行此计算。

这里的前后是沿路径顺序，不是空间上相对的两个支承端：单侧悬臂从同一支承侧伸出再折返，也可计入 `two_sided_run_count`。真实 cantilever 样例已出现此情况，不能把该数值直接用于桥接合格或自动免支撑判断。

`planned_support_projection` 是组内独立的逐实例观察。一次归集整板当前 `SupportLayer.support_fills`，按实例 shift 转到板坐标并按 print_z 合并实际线宽足迹；包括合并筏层 owner 的路径，不读 `raft_merge_backup`，不按 enable_support 或本地列表是否为空猜测整板支撑。普通支撑 slice_z 可为 -1、同层路径 height 可不同，因此只以 print_z 为支撑打印平面。非法 Z/路径使新区块未知，不使原模型指标失效。

目标为 `(本层截面−前层截面)∩本层计划路径`，首层用本层交集。依支撑 Z 降序，对尚未匹配的目标仅分配不高于模型本层 print_z 的最高正交集，记录分区面积和 `模型 bottom_z−支撑 print_z`，再扣除已分配区域；较近但 XY 不相交的层不会遮住下方匹配。保留正/零/负差值，同层分配面积不重复相加；它不是实际接触间隙或承托率。没有路径是已知空，非法层序/路径为 unknown，首层无前层不影响此项。Web 按实例/模型层展示同条匹配，不拼凑跨层最小差值/最大面积；不做质量或自动采用判断。

每个已分配支撑高度行附加 `intervening_model_projection:{complete,area_mm2}`，统计该行目标区域与严格位于 `支撑print_z < 模型print_z < 目标print_z` 的整板模型计划路径投影重叠。使用perimeters/fills而非实心截面，按各实例shift查询，共享Layer只复用局部计算；多个层/实例重叠只计一次。支撑与目标同Z时新项false/null；没有匹配行不虚构零。非有限模型Z无法定位使新项未知，有限Z的非法几何/路径仅影响查询到的区间；旧分配面积和完整性不因新项未知而改变。即使已覆盖全部目标，也核查剩余区间层完整性。

这是打印平面之间的模型路径投影，不是三维实体遮挡：不按路径厚度构造材料体积，不确认逐对象打印时材料是否已经存在，不验证支撑刚度、桥接锚定和实际接触。有效的0仅表示此口径下没有重叠，不表示支撑有效；正面积也不是打印失败。Web复用原高度行独立显示新面积、未知、不适用及旧报告未提供，不增加A/B/CSV或阈值。

来源标记、配置块、机型、喷嘴、耗材直径及硬度影响校验和统计。硬度显式值优先；喷嘴硬度 0 时按类型取值，类型未知才跳过；耗材要求 0 也跳过。不能为消除警告修改耗材参数。

当前分支可检索的配置键：`nozzle_hrc`、`nozzle_type`、`required_nozzle_HRC`、`filament_diameter`。定义与默认值集中于 PrintConfig；实际生效仍要读取对象覆盖后的值。

## 失败与取消

`source_surface_layer_alignment` 独立于原源体积采样/路径完整性，按source MODEL_PART体积汇总两项参考量。实际源层带为double `slice_z±height/2`，非水平面与层带交于Z区间`[a,b]`时，将其中源面点沿Z映射到切片器实际使用的float `slice_z`，最大法向分量为 `max(|a-z|,|b-z|)*|nz|/||n||`。共面细分不改变最大值（浮点尾差除外）；竖面可为0，无适用面则count=0/max=null。水平面另计到所有保留层带边界的最近高度差，再按volume取最大，范围外源面也统计。不把两项合并成评分，不把printZ/筏层位移代替源层带。

源顶点沿用切片float变换，double叉积计算法向，支持非均匀缩放；只统计正向源体积，未扣除内部重叠面、负体积或修改器形成的最终布尔边界。两项均不是打印阶梯体距离、路径存在证明或实物精度。层表无效/无层/非法源几何使新区块对应volume未知，不影响原source_volume_sampling；无适用和0区分。使用有序层带定位面Z区间，遍历中检查取消，无新Clipper或路径生成。Web仅独立展示，不加A/B/CSV或选择规则。

损坏配置、未知来源、缺少耗材映射和不合法 T 指令要分别排查。预估时间取决于机器限制，不等于实测打印时间；警告和后台切片错误的级别不同。

计划足迹按层保留临时多边形，层/区域/岛间检查取消；单次 Clipper 运算不能中途打断。复杂层会增加偏移、合并和逐岛求交开销；只有请求报告的 CLI 进入此路径，普通 GUI/CLI 不新增该成本。性能证据不当作服务器吞吐保证。

开放空白计算增加计划孔合并/差集；仅发现正面积外界贡献后逐孔做带包围盒筛选的交集计数。逐层释放、不把多边形写入报告；很多填充孔时仍有额外成本，当前稀疏小样例性能与既有多岛非确定性边界见实施记录，不提前增加空间索引或业务阈值。

间距计算单岛直接跳过，多岛按层保留边界与树，岛/查询循环检查取消。树按岛建立一次，岛对最坏二次遍历；全局最小距离的包围盒剪枝减少实际查询，但不作复杂模型吞吐保证。没有新增业务阈值或修改共享几何/路径算法。

支撑足迹每个打印 Z 只合并一次，查询先用包围盒排除，目标完全分配后停止；归集和逐层/实例/高度循环检查取消。最坏仍需遍历模型层×支撑高度且保存各高度支撑足迹；只在请求报告时付出该开销，性能证据见实施记录，不提前承诺复杂模型吞吐。

中间模型观察仅保留有实例的模型层元数据并按printZ排序，命中窗口才计算计划足迹，报告局部缓存至本次报告结束。每层最多额外做一次足迹合并，查询将小目标移到实例局部坐标求差；候选层/区域/实例循环检查取消，单次Clipper不能中途取消。最坏仍会缓存全部命中层，不把小样例成本视为复杂模型内存或吞吐上界。
