## 职责与边界

本模块负责 G-code 解析、统计与预览，及显式请求的只读切片报告。归属以[模块清单](../modules.json)的 `gcode-preview` 为准。报告不是打印合格证，不自动修复、改参或选优。

## 入口与调用

- [GCodeReader.cpp](../../../src/libslic3r/GCodeReader.cpp)：逐行解析和坐标状态。
- [GCodeProcessor.cpp](../../../src/libslic3r/GCode/GCodeProcessor.cpp)：运动、角色、材料与时间统计。
- [SliceAnalysis.cpp](../../../src/libslic3r/SliceAnalysis.cpp)：`make_slice_analysis_report` 只读本次 Print 与已完成的 GCodeProcessorResult；不再次切片。
- [GCodeViewer.cpp](../../../src/slic3r/GUI/GCodeViewer.cpp)、[GUI_Preview.cpp](../../../src/slic3r/GUI/GUI_Preview.cpp)：原生 GUI 路径预览，不调用报告核心。

CLI 的 `slice_analysis_requested` 通过 `Print::export_gcode` 默认 false 参数、`GCode(bool)` 传到 `GCodeProcessor(bool)`。reset 清数据但保留实例开关；normal 估时器的内部 `analysis_enabled` 继承该开关，不新增用户配置。普通 GUI、独立 G-code 预览及未请求报告的 CLI 不收集材料 cap map、块快照、峰值/超 cap 距离与层材料身份。角色运动统计已整体删除；原预览、耗材、估时和 M73 继续工作。固定字段和少量分支仍存在，不宣称零开销。

## 核心流程

### 保留的几何与配置证据

`objects` 区分源对象、切片组和实例；记录模型层、支撑层、首末打印 Z、层高范围、首模型层截面及配置。对象/区域分别快照，不用全局预设冒充最终有效参数。内部 `PrintObject::size()` 不输出为精确缩放组尺寸。

`planned_layer_coverage` 每次只保留一模型层的临时几何：合并 `lslices`，按 perimeters/fills 实际线宽构造足迹，不重复统计已复制的 thin_fills。保留：

- 截面/路径面积，以及完全无路径岛的数量与面积；不再额外计算截面与路径的重复交集面积。
- 闭孔面积、路径侵入面积、完全被路径覆盖的闭孔数量；扣除孔内独立材料岛。
- 配置后的实体填充目标及未覆盖面积；不再拆分重复的顶/底目标差集。普通稀疏内部不算实体目标，刻意降低顶底密度留下的空隙也不是自动认定的缺陷。
- 岛数量、岛间最小距离、同岛平行材料宽度和空白宽度。
- 模型层序号、采样/打印 Z、层高与计算完整性，供定位和区分无样本/未完成。

`planned_layer_coverage.solid_fill_peak` 仅解释每个切片组**总实体未覆盖面积最大的一个模型层**（相同最大值取首层），不是逐类全模型最大值。复用既有差集，仅保留峰值层的一份临时差集，最后按原 `Surface::is_solid()` 目标拆成非桥接顶底表面、内部实体、桥接；跨类重叠先单列 `mixed_area_mm2` 再从各类扣除，区域/实例不重复计数。不输出坐标，不恢复逐层顶/底重复差集；最大值未变，新增分类也不修改切片规划。任一模型层不完整则整个峰值摘要未知；无模型层未知；全层未覆盖均为0时分类均为0、层位为null。分类布尔运算可有整数裁剪量化余差，消费者按同层/同Z/最大值以及各类和校验。

该摘要供Web在壳层、连接与桥接处理项中关联不同检查参数：表面密度/补缝范围与过滤、内部窄实体策略、桥接承托/速度/流量/冷却。桥接线间可能有意留空，最大实体空隙不能直接当作表面破损或增流量触发条件；Orca桥接目标也不等于Blender已确认两端承托。普通GUI没有报告入口，CLI显式开启才计算；默认关闭不增加模型扫描。旧报告缺摘要只保留旧观察，不猜来源或补0。

`unprinted_peak` 在无路径岛总面积最大的一个层（同值首层），将既有无路径岛与最终 `LayerRegion::slices` 并集求交/差，区分仍保留在分区轮廓与已不保留的面积。只定位处理阶段，不能证明具体过滤参数、输入模型缺件或三维断裂。`hole_intrusion_peak` 在孔交叠面积最大的一个层（同值首层），对既有交叠区区分普通内外墙、补缝、桥接/悬垂、其他填充的名义足迹；跨类重叠先单列并从各类扣除。只遍历该层路径，不保存全模型角色几何/坐标，不将一个峰值来源推广到所有层。两摘要与solid峰值保持同样的全层完整性、零/未知和取消规则，原逐层值不变；消费者核对同组最大值、层/Z、分类和后才使用。墙主导的孔交叠不应直接指向关闭补缝或自动孔补偿。

不输出把正常稀疏填充也算在内的整体截面未覆盖面积，或无直接调参用途的区域分裂/跨岛连通计数。岛/孔裁剪先用原包围盒排除必不相交候选，再作原整数布尔运算；不删除微小正面积。无挤出/零流量排除，非法路径或层几何使覆盖指标 null，不冒称完整。原生合法 Cura V1 模型层重叠不改生成规则。

`section_min_island_gap_mm` 对每层合并后的正面积岛（含孔边）建立线段 AABB，取双向边界端点到线段的最小距离。少于两岛为不适用 null，不完整为未知，零不自动表示粘连；不跨实例/组，也不把同岛开槽当岛间距。

`parallel_boundary_clearance` 使用原线段 Voronoi，仅同岛严格平行、方向相反的有限主边；材料和空白分别取最小值。坐标域超限或原图验证失败仅本块未知，不旋转修复数据。无适用边为完整/null，不等于没有薄区；不是通用最薄壁、三维厚度或实际打印公差。象脚层的参考截面可能未补偿，不能直接当最终实物尺寸。

仅保留顶层 `planned_plate_bed_footprint`，按各路径自身 print_z-height 判断贴床；模型/支撑按实例 shift，Brim 已在板坐标，不重复变换。输出模型、支撑及筏、Brim、总并集四面积，重叠不重复计入总面积。非法输入整块未知，空类别为0；不再生成各连通区域与范围框，也不额外计算无消费者的逐实例模型底面面积。

### 保留的 G-code 指标

总时间及各材料耗材体积读取处理器既有结果；材料保留 total/other/support/wipe_tower/flush 分类，层序列数仅作冷却观察校验。不重复输出逐层时长、名义流量范围、质量评分或接缝计数；仅在耗材账本出现的材料也保留，原任务预计克重不变。

`gcode.quality_paths` 在报告原有 moves 遍历中按材料及原生角色汇总实际正挤出路径长度、段数、指令速度/风扇范围和名义线宽/层高。只含内外墙、悬垂墙、桥接、实体填充、顶底面、缝隙填充、支撑及接触面等质量核查角色；不含空移、回抽、零E或自定义挤出，不存坐标或每段明细。Native arc 使用既有 travel_dist，非端点弦长。无效数值使该材料/角色整行 unknown，其他行保留；没有该角色不是没有几何风险。Web将其与请求参数分开呈现，桥接原生角色不等于Blender确认两端承托，小轮廓没有独立角色，不能从外墙范围证明命中。仅显式报告执行该工作，不向普通GUI/默认CLI增加采集或扫描。

每行 `width_height_observation` 在同一遍历中逐段比较名义width/height，输出低于同段层高的段数/路径长度、最小比对应宽高与G-code端点Z；不以全局最小宽/最大高拼接，不保存逐段数据。桥接/悬垂角色使用不同挤出模型而不适用，非法行未知，完整且没有低于层高的路径才是计数/长度0。宽高比不是喷嘴/耗材标定的可打印阈值，不能据此宣称失败或自动剔除路径；有该观察时不把面积覆盖增加直接当作已验证的质量收益，不直接增流量或降最小线宽。`filter_out_gap_fill` 控制长度，不是线宽下限。缺少端点Z仅位置未知，宽高观察仍保留。

G1 非挤出段不再额外计算距离；原预览使用的挤出距离和圆弧处理不变。角色 `estimated_motion` 类型、观察器和容器已删除，不能仅在 JSON 层隐藏后继续计算。名义流量重复比较也停止，以考虑加减速的下列观察作为核心证据。

`estimated_peak_flow` 快照块创建时的线性 E、丝径及 M221，并与同一块最终峰值速度相乘；不把跨块最大值相乘、不重复倍率。缺少元数据、非法丝径、不支持的体积 E/单位模式按材料保留未知，旧耗材与估时不改。

`estimated_flow_cap_distance` 使用同一块加速、匀速、减速阶段的距离积分，统计严格超过配置 cap 的路径比例；等于上限不算超过，不把峰值超限的一整段全部算入。0倍率有效；无参与路径为0/0/比例null。cap 身份变化、非法值或残块只影响对应新观察。

最终阶段端点仅接受相对段长两次float运算量级的舍入误差；积分在校验后钳制观察副本端点，不修改规划器、原运动或时间。超出该范围/非有限/残块仍按材料未知。消费者不能把缺项补零或按名义流量冒充加减速后流量；PAM选参不依赖这两个切后观察，已有流量限制仍由原生切片执行。旧报告缺项兼容保留。

`layer_time_threshold_observation` 通过 finalize 中保留的真实层序列/材料身份，对参与序列时长与该材料现有冷却阈值作严格比较；不按 Z 或相同估时猜身份。禁用、阈值0或无参与序列为不适用；缺身份、非法阈值/时间为未知。首序列可能包含准备时间，序列时长不是局部冷却时长，也不是自动降速是否成功的结论。

上述采集保持 reset、结果复制、finalize 语义，未定型残块仍使对应材料未知，不为生成报告改变原估时器消费顺序。界面只将有调参意义的成本、窄宽/孔缝、流量/冷却证据作为核心展示，不自动评分或采用方案。

### 已停止的报告工作

不再计算三维名义目标/路径连通、未覆盖体积/位置、顶底连续深度、路径实体深度、跨层支撑/桥接/联合材料投影、源体积采样/源面层位偏差、闭墙环转角及各区域坐标。专用 `SliceAnalysisGeometry` 精确集合实现和 CMake 登记一起移除，不保留旧计算或版本开关。原 CGAL 模型修复与 MeshLib 不属于此删除范围。原始方案和验证流水留在历史实施记录，不作为当前输出合同。

## 配置与约束

只在显式 CLI 报告路径运行；不新增参数、自动选参或原生 GUI 功能。原生成器、分盘、筏层和模型首层参数归属均不修改。报告仍使用同一 schema 1，消费者应读取保留字段，不能要求已删除诊断存在。

JSON 数值必须有限；无样本、不适用、未知与合法零分开。对象与材料快照保留原序列化约定，非有限 cap/冷却阈值单项 null。流量、时间、覆盖均是规划证据，不证明实物强度、承托、融合、尺寸或打印成功。

喷嘴硬度等原校验仍由配置生效值决定：`nozzle_hrc` 显式优先，0按 `nozzle_type` 查找，未知类型/材料要求0跳过；不要为消除警告修改材料参数。

## 失败与取消

层、区域、路径与岛/查询循环检查取消，单次 Clipper/Voronoi 内部不保证立即中断。保留二维复杂层仍有计算成本，不以简单样例承诺吞吐。报告写出失败沿 CLI 原有错误路径，已生成 G-code 保留；普通未请求报告场景没有报告计算或写出。

## 修改与验证

`tests/fff_print/test_slice_analysis.cpp` 验证保留指标口径、零/未知、取消、配置与几何不变、分析开关和处理器重置，以及禁止输出已删除字段。`scripts/test_cli_slice_analysis.py` 验证开关、非法组合、输出保护及最终打印指令/有效配置不变。`scripts/test_cli_slice_features.py` 保留真实 Classic/Arachne、孔缝/细笔画、稀疏内部/顶面、支撑/筏等场景；不再要求已删除诊断。

当前增补真实支撑段缩减的舍入红绿用例、角色/材料隔离、空移/自定义/零E排除、非法单行、真实M106和圆弧长度核查；峰值实体来源另覆盖重复区域去重、桥接/内部/表面混合、跨类重叠、非峰值层非法、零与空层。已有开关、残块、预览/估时/耗材一致性回归保留。Web兼容旧报告，验证未提供不补零、执行证据独立于参数请求匹配、不重复归因共用参数。

当前构建身份、实际运行结果及 GUI 交接见[实施记录](../validation/2026-10-18-slice-analysis.md)。原生 GUI 没有该报告入口，需核对普通切片/预览不回归；Compare Web 是独立消费界面。自动化不能替代 Windows/Linux 打包、浏览器联调或实印验收。
