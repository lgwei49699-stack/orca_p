## 职责与边界

本模块负责场景、对象与交互编辑。归属以[模块清单](../modules.json)的 `scene-editing` 为准。

## 入口与调用

- [GUI_ObjectList.cpp](../../../src/slic3r/GUI/GUI_ObjectList.cpp)：`ObjectList` 管理对象树及选择索引，将模型／体积／实例选择映射到编辑动作。
- [Selection.cpp](../../../src/slic3r/GUI/Selection.cpp)：`Selection` 维护场景选中项、剪贴板与变换操作，关联 GLVolume 和模型实例。
- [GLGizmosManager.cpp](../../../src/slic3r/GUI/Gizmos/GLGizmosManager.cpp)：`GLGizmosManager` 初始化并切换编辑工具，分发鼠标拾取、渲染和工具状态。
- [ModelReconstructionDialog.cpp](../../../src/slic3r/GUI/ModelReconstructionDialog.cpp)：近似形状风险确认、毫米参数、原件／候选 XY/XZ/YZ 中截面对比及显式采用；由 `ObjectList::reconstruct_model` 调共享重建核心。

## 核心流程

对象树映射 ModelObject／ModelVolume／实例和盘，Selection 维护场景选中集合；GLGizmosManager 将移动、旋转、切割、涂色、支撑绘制等操作分派给 gizmo。几何提交后更新包围盒、撤销快照、盘归属并使切片失效。

macOS 对象列表的可编辑性查询只读，真实图标/耗材单击、名称双击或键盘编辑请求由平台适配转发。编辑入口过滤无效 item 和受抑制列表事件；两处落床入口必须在取撤销快照前校验对象索引范围及对象指针，盘/盘外等非对象行不能被当作模型。CLI 无该交互，不因此改变检测/修复协议。

重建入口先检查 FFF 准备视图、编辑工具已关闭及单对象适用性，用户确认风险和参数后在可取消进度窗口中运行独立 worker。参数页说明最多三档粗化尝试共用预算，“表面偏差告警阈值”不再是硬性拒绝线；仅要求三参数有限正值及 offset 不大于 alpha/4。候选成功后展示相同物理坐标下的三个真实中截面、尺寸、底面 ΔZ、双向采样距离、包围盒偏差及最终有效 alpha/offset，超阈值单独告警；三剖面不能覆盖全部特征，采样不是最大误差保证。所有候选须明显提示网格检查通过不代表内部结构保持或已经可打印，不只对自交来源提示。

参数页默认勾选“包裹前尝试闭合开放边界”，同时说明可能填上有意开口，可取消以保留原汤包裹策略。选项传入共用核心，不在 GUI 自行补面。预览根据实际报告区分“已加入封口面”与“未能封闭、可能形成薄壳导致墙或实体路径缺失”；闭合实体不显示不适用的封口警告。生成/预览不等同采用，已有风险确认、原件保留及撤销语义不变。10-07 新打包版已实操默认/关闭预闭合对照、两类风险提示、采用、菜单撤销/重做、保存退出重开和实际切片；同配置下默认恢复完整主体，关闭仍为碎外墙。闭合输入不误报封口，“保留原模型”不改变网格/摆放；英文/暗色/当前版运算取消等未验项继续在主记录/GUI 交接保留，不把局部通过等同发布验收。

参数和预览窗口的正文独立滚动，确认／取消按钮固定在正文之外；初始窗口按父窗口所在显示器可用工作区限幅并修正位置，不再以全部正文高度锁定最小尺寸。小屏／高 DPI 的实际可读性及键盘操作仍需 GUI 手测。

参数窗口的取消按钮显式使用项目已有 `Cancel` 翻译，避免原生标准按钮在简中界面仍显示英文。

大模型重建参数页显示当前对象按共享规则选择的 worker 秒数及 MiB，明确为资源上限、不是预计完成时间；物理 RAM 约束和输入 300 万面上限与 CLI 相同。显示后的预算直接用于任务，不在运行时另选不同档位。场景导入可能先有原生清理（例如龙模型去掉一个面），比较两端时需核实实际网格及变换，不能仅凭文件名断言相同输入。10-07 用户大模型 GUI 回传已覆盖候选采用、切片及首次导出；取消、撤销/重做等其他场景按[验证记录](../validation/2026-10-04-smart-print-engine.md)分别判断，不将首次导出通过扩大为全量 GUI 验收。

选择“采用候选”后复核源身份、体积元数据、预设完整配置、Plater 配置及所在打印板配置；先准备无分配提交，再取 Undo 快照、解除旧选择／设置指针、替换候选、刷新场景与切片状态，最后排对象网格和工程备份。“保留原模型”、取消、拒绝或过期结果不提交。备份排队不代表磁盘写入完成。

## 配置与约束

对象参数、体积／部件参数和变换是不同层次。模型部件、负体积和修改器不能按同一种网格直接导出。模型局部坐标、实例变换和盘原点必须分清。

重建的普通单体积、单实例、无绘制及附属结构限制由共享核心决定，不在 GUI 自动清除；一个体积内的开放边界、多壳及自交等缺陷允许重建，不能继续套用旧大开口／单壳拒绝预期。默认保留原摆放，包括有意沉床；只在用户勾选沿 Z 落床时平移候选后采用。参数页和预览页仍加粗标注“实验性近似候选”。候选与采用结果均不能称为可打印，当前没有独立同有效配置诊断试切片，采用后仍要求重新切片并逐层检查；真实样例收益及未完成的 GUI／平台验收单独记录。旧“修复模型”的选择及算法保持原行为。

## 失败与取消

没有选中项时不能索引空集合；取消交互应恢复原状态。修改几何的操作需保持对象 ID 与已保存绘制信息对应关系，不可绕过 Model 的失效与备份机制。

## 修改与验证

修改入口在 GUI_ObjectList 与具体 gizmo；检查多选、删除、拆分／合并、撤销重做、切换盘及保存重开。涂色还需 SavedPainting 回归，交互正确不等于切片已验证。

现有测试/工具范围：`tests/libslic3r/test_saved_painting.cpp`。测试范围与实际通过记录分开，执行要求见[验证规范](../validation.md)。

重建共享规则测试见[模型修复模块](model-repair.md)；菜单、确认／取消、图形对比、Z 选择、Undo/Redo、保存重开及待试切片观察必须按[GUI 交接](../validation/2026-10-05-reconstruction-gui.md)手动验证，不能从核心单元测试推定通过。构建与测试证据复用[主记录](../validation/2026-10-04-smart-print-engine.md)。
