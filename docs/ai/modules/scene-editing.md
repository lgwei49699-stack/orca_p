## 职责与边界

本模块负责场景、对象与交互编辑。归属以[模块清单](../modules.json)的 `scene-editing` 为准。

## 入口与调用

- [GUI_ObjectList.cpp](../../../src/slic3r/GUI/GUI_ObjectList.cpp)：`ObjectList` 管理对象树及选择索引，将模型／体积／实例选择映射到编辑动作。
- [Selection.cpp](../../../src/slic3r/GUI/Selection.cpp)：`Selection` 维护场景选中项、剪贴板与变换操作，关联 GLVolume 和模型实例。
- [GLGizmosManager.cpp](../../../src/slic3r/GUI/Gizmos/GLGizmosManager.cpp)：`GLGizmosManager` 初始化并切换编辑工具，分发鼠标拾取、渲染和工具状态。
- [ModelReconstructionDialog.cpp](../../../src/slic3r/GUI/ModelReconstructionDialog.cpp)：近似形状风险确认、毫米参数、原件／候选 XY/XZ/YZ 可选位置截面对比及显式采用；由 `ObjectList::reconstruct_model` 调共享重建核心。

2026-11-03 截面默认仍取原件与候选联合包围盒中心，可分别输入 Z/Y/X 毫米坐标，再点“更新截面”。范围由联合包围盒限定，步进0.1mm、显示三位小数；输入期间不自动重算，按钮仅更新位置改变的剖面，复用预览几何，不重建候选或改变采用参数。原件/候选在同一物理位置、同一比例绘制，标题显示实际切面位置。共面三角形仍按既有剖面算法省略，不是轮廓投影。该控件为GUI审阅交互，CLI没有对应界面；两端候选与共享检查不变。Mac已验证中心看不到的0.1mm宽偏心盲孔可在指定截面显示原件深槽与候选填平差异；“保留原模型”后的工程网格与变换精确相同。三个选定截面、无拓扑告警均不能证明所有孔腔保留，见[当前记录](../validation/2026-10-31-cgal-621-upgrade.md)。

2026-11-03 重建候选页在共享报告已完成拓扑比较且检测到变化时，单独加粗提示闭合表面或贯通孔连通结构变化，不依赖表面距离是否超阈值。原件无效时不显示已确认变化，继续保留通用近似风险提示；数值相同不表示结构保留。移除无实际状态赋值的旧 `interior_check_status=not_preserved` 显示分支，采用/保留/Z位置逻辑不变。Mac小孔原件在3mm诊断阈值下仍显示结构告警；保留后模型XML与基线完全一致，见[当前记录](../validation/2026-10-31-cgal-621-upgrade.md)。

对象树映射 ModelObject／ModelVolume／实例和盘，Selection 维护场景选中集合；GLGizmosManager 将移动、旋转、切割、涂色、支撑绘制等操作分派给 gizmo。几何提交后更新包围盒、撤销快照、盘归属并使切片失效。

macOS 对象列表的可编辑性查询只读，真实图标/耗材单击、名称双击或键盘编辑请求由平台适配转发。编辑入口过滤无效 item 和受抑制列表事件；两处落床入口必须在取撤销快照前校验对象索引范围及对象指针，盘/盘外等非对象行不能被当作模型。CLI 无该交互，不因此改变检测/修复协议。

重建检查 FFF 准备视图、编辑工具和单对象适用性；无 SDK 时提示不可用。参数页显示体素尺寸（未指定时初始 0.30 mm，可编辑，显式值优先）和偏差告警阈值，删除 alpha/offset/预封口。CLI仍要求显式体素，配套Slicer服务新默认同为0.30mm，原有配置覆盖及任务快照保留。粗体素换取性能，不能把0.30mm当作最大外形误差；核心对生成候选及坐标往返执行完整网格检查；CLI 导出校验面数/文件长度并记录哈希，不再回读排序所有三角面。任务在同进程后台运行，主线程轮询并等待取消结束。成功后对比相同物理坐标的 XY/XZ/YZ 截面、尺寸、底面 ΔZ、采样偏差及实际体素尺寸；三剖面/采样不能证明完整结构或可打印性。

历史 Alpha Wrap 界面（本轮已删除，非当前行为）：参数页默认勾选“包裹前尝试闭合开放边界”，同时说明可能填上有意开口，可取消以保留原汤包裹策略。选项传入共用核心，不在 GUI 自行补面。预览根据实际报告区分“已加入封口面”与“未能封闭、可能形成薄壳导致墙或实体路径缺失”；闭合实体不显示不适用的封口警告。生成/预览不等同采用，已有风险确认、原件保留及撤销语义不变。10-07 新打包版已实操默认/关闭预闭合对照、两类风险提示、采用、菜单撤销/重做、保存退出重开和实际切片；同配置下默认恢复完整主体，关闭仍为碎外墙。闭合输入不误报封口，“保留原模型”不改变网格/摆放；英文/暗色/当前版运算取消等未验项继续在主记录/GUI 交接保留，不把局部通过等同发布验收。

参数和预览窗口的正文独立滚动，确认／取消按钮固定在正文之外；初始窗口按父窗口所在显示器可用工作区限幅并修正位置，不再以全部正文高度锁定最小尺寸。小屏／高 DPI 的实际可读性及键盘操作仍需 GUI 手测。

参数窗口的取消按钮显式使用项目已有 `Cancel` 翻译，避免原生标准按钮在简中界面仍显示英文。

参数页显示共享规则选择的秒数/MiB，说明是整个应用的协作预算而非预计完成时间/硬上限；显示值直接传入任务。SDK/验收阶段可能延迟响应取消。源模型、显式采用、沿 Z 落床和 Undo 保留。入口变更后的 GUI 仍待手测，不沿用旧 Alpha GUI 结果，见[当前交接](../validation/2026-10-31-cgal-621-upgrade.md)。

选择“采用候选”后复核源身份、体积元数据、预设完整配置、Plater 配置及所在打印板配置；先准备无分配提交，再取 Undo 快照、解除旧选择／设置指针、替换候选、刷新场景与切片状态，最后排对象网格和工程备份。“保留原模型”、取消、拒绝或过期结果不提交。备份排队不代表磁盘写入完成。

## 配置与约束

对象参数、体积／部件参数和变换是不同层次。模型部件、负体积和修改器不能按同一种网格直接导出。模型局部坐标、实例变换和盘原点必须分清。

重建的普通单体积、单实例、无绘制及附属结构限制由共享核心决定，不在 GUI 自动清除；一个体积内的开放边界、多壳及自交等缺陷允许重建，不能继续套用旧大开口／单壳拒绝预期。默认保留原摆放，包括有意沉床；只在用户勾选沿 Z 落床时平移候选后采用。参数页和预览页仍加粗标注“实验性近似候选”。候选与采用结果均不能称为可打印，当前没有独立同有效配置诊断试切片，采用后仍要求重新切片并逐层检查；真实样例收益及未完成的 GUI／平台验收单独记录。旧“修复模型”的选择及算法保持原行为。

## 失败与取消

没有选中项时不能索引空集合；取消交互应恢复原状态。修改几何的操作需保持对象 ID 与已保存绘制信息对应关系，不可绕过 Model 的失效与备份机制。

## 修改与验证

盘菜单新增“修复当前盘 / 修复全部盘”，按模型对象收集、去重目标后调用既有高级修复事务，未复制算法。对象多个实例共用网格，因此当前盘实例修复也更新该对象其他盘实例；全部盘包括工程内全部对象。原件/取消、绘色、Undo、备份与单对象入口相同。纹理导入弹窗按官方提供直接导入/修复后导入/取消，只有修复后才请求共享高级修复，失败不静默裸导入。GUI 操作待验，见[本轮交接](../validation/2026-10-31-cgal-621-upgrade.md)。
